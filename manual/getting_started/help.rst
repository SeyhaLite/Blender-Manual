  ប្រព័ន្ធជំនួយ (Help System)

Blender មានជម្រើសជំនួយជាច្រើន ទាំងដែលមានស្រាប់ក្នុងកម្មវិធី និងតាមគេហទំព័រ។


ប្រអប់ព័ត៌មាន (Tooltips)
=========================

.. figure:: /images/getting-started_help_tooltip.png

   ប្រអប់ព័ត៌មានរបស់ឧបករណ៍ជ្រើសរើសម៉ាស៊ីន render (Renderer selector) ក្នុង Info Editor។

បន្ទាប់ពីដាក់ទ្រនិចកណ្ដុរលើប៊ូតុង ឬការកំណត់មួយមួយភ្លែត ប្រអប់ព័ត៌មាននឹងលេចឡើង។


ធាតុផ្សំ
-----------

ប្រអប់ព័ត៌មានដែលអាស្រ័យលើបរិបទ អាចមានធាតុខ្លះក្នុងចំណោមធាតុទាំងនេះ៖

Short Description
   ព័ត៌មានលម្អិតពាក់ព័ន្ធ អាស្រ័យលើធាតុគ្រប់គ្រង។
Shortcut
   ផ្លូវកាត់ក្ដារចុច ឬកណ្ដុរ ដែលភ្ជាប់នឹងឧបករណ៍។
Value
   តម្លៃនៃលក្ខណសម្បត្តិ (property)។

   ការដាក់ទ្រនិចលើលក្ខណសម្បត្តិពណ៌ នឹងបង្ហាញការមើលជាមុននៃគំរូពណ៌ធំ
   ព្រមទាំងតម្លៃ hexadecimal, RGBA និង HSVA របស់ពណ៌នោះ។

   .. figure:: /images/getting-started_help_color.png

      ប្រអប់ព័ត៌មានដែលបង្ហាញព័ត៌មានពណ៌។

Library
   ឯកសារប្រភពនៃវត្ថុសកម្ម។ សូមមើលផងដែរ
   `Linked Libraries <https://docs.blender.org/manual/en/5.2/files/linked_libraries/index.html>`__។
Disabled (red)
   មូលហេតុដែលតម្លៃមិនអាចកែបាន។
Python
   នៅពេលដែល :ref:`Python Tooltips <bpy.types.PreferencesView.show_tooltips_python>` ត្រូវបានបើក
   កន្សោម Python មួយនឹងត្រូវបានបង្ហាញសម្រាប់
   `ការសរសេរស្គ្រីប <https://docs.blender.org/manual/en/5.2/advanced/scripting/index.html#scripting-index>`__
   (ជាធម្មតាជា operator ឬ property)។

ការចូលមើលសៀវភៅណែនាំតាមបរិបទ
==============================

.. reference::

   :Mode:      គ្រប់របៀបទាំងអស់
   :Menu:      :menuselection:`Context menu --> Online Manual`
   :Shortcut:  :kbd:`F1`

អ្នកប្រហែលជាចង់ចូលមើលជំនួយសម្រាប់ឧបករណ៍ ឬតំបន់មួយពីខាងក្នុង Blender។

ដើម្បីធ្វើដូច្នេះ សូមដាក់ទ្រនិចលើឧបករណ៍ ឬប៊ូតុងដែលអ្នកត្រូវការជំនួយ
ហើយប្រើផ្លូវកាត់ក្ដារចុច ឬធាតុក្នុងម៉ឺនុយបរិបទ ដើម្បីចូលមើលទំព័រនៃសៀវភៅណែនាំយោងនេះ
ពីខាងក្នុង Blender។ នេះនឹងបើកទំព័រគេហទំព័រដែលពាក់ព័ន្ធនឹងប៊ូតុងនៅក្រោមទ្រនិច
ដោយគាំទ្រទាំងប៊ូតុងឧបករណ៍ និងប៊ូតុងតម្លៃ។

.. note::

   បច្ចុប្បន្នយើងមិនទាន់មានការគ្របដណ្ដប់ ១០០% ទេ។ អ្នកអាចឃើញការជូនដំណឹង
   នៅក្នុងរបារបញ្ជា info ប្រសិនបើឧបករណ៍មួយគ្មានតំណទៅសៀវភៅណែនាំ។

   ក្នុងករណីផ្សេងទៀត ប៊ូតុងអាចភ្ជាប់ទៅផ្នែកទូទៅជាងរបស់ឯកសារណែនាំ។

.. note::

   ជម្រើស *Online Manual* នេះបើកសៀវភៅណែនាំភាសាអង់គ្លេសផ្លូវការ។
   វាមិនទាន់អាចចង្អុលទៅកាន់កំណែបកប្រែភាសាខ្មែរនេះដោយស្វ័យប្រវត្តិទេ។

ម៉ឺនុយ Help
============

តំណភ្ជាប់គេហទំព័រ
-----------------

ជម្រើសដំបូងៗនៃម៉ឺនុយនេះផ្ដល់តំណផ្ទាល់ទៅកាន់គេហទំព័រដែលពាក់ព័ន្ធនឹង Blender។
តំណដូចគ្នាក៏អាចរកបាននៅក្នុង :doc:`អេក្រង់ចាប់ផ្ដើម </interface/window_system/splash>` ដែរ។

:doc:`Manual </index>`
   នេះជាតំណទៅកាន់សៀវភៅណែនាំ Blender ផ្លូវការ (ដែលអ្នកកំពុងអាននេះជាកំណែបកប្រែភាសាខ្មែរ)។
`Support <https://www.blender.org/support>`__
   ភ្ជាប់ទៅកាន់គេហទំព័រផ្សេងៗ ដែលផ្ដល់ទាំងជំនួយពីសហគមន៍ និងជំនួយវិជ្ជាជីវៈ។
`User Communities <https://www.blender.org/community/>`__
   បញ្ជីគេហទំព័រសហគមន៍ និងកន្លែងផ្ដល់ជំនួយជាច្រើនផ្សេងៗ។
`Get Involved <https://www.blender.org/get-involved>`__
   ស្វែងយល់ពីរបៀបផ្ដល់អ្វីមួយត្រឡប់ទៅសហគមន៍ Blender វិញ
   ដោយចូលរួមចំណែកក្នុងគម្រោង ឬបរិច្ចាគ។
`Release Notes <https://developer.blender.org/docs/release_notes/>`__
   តំណទៅកាន់កំណត់ត្រាការចេញផ្សាយសម្រាប់ Blender កំណែបច្ចុប្បន្ន។

----

`Report a Bug <https://projects.blender.org/blender/blender/issues/new?template=.gitea%2fissue_template%2fbug.yaml>`__
   កម្មវិធីតាមដានកំហុសរបស់ Blender (ត្រូវការការចុះឈ្មោះ)។
   សម្រាប់ព័ត៌មានបន្ថែមអំពីការរាយការណ៍កំហុស សូមមើល
   `Reporting a Bug <https://docs.blender.org/manual/en/5.2/troubleshooting/report_bug.html>`__។


.. _help-system-info:

រក្សាទុកព័ត៌មានប្រព័ន្ធ (Save System Info)
--------------------------------------------

មុខងារនេះទាញយកព័ត៌មានប្រព័ន្ធ ដែលអាចមានប្រយោជន៍សម្រាប់រួមបញ្ចូលក្នុងរបាយការណ៍កំហុស
ការត្រួតពិនិត្យការកំណត់រចនាសម្ព័ន្ធ ឬការធ្វើរោគវិនិច្ឆ័យបញ្ហា។

អ្នកនឹងត្រូវបានសុំឱ្យរក្សាទុកឯកសារអត្ថបទមួយឈ្មោះ ``system-info.txt``។

វាមានផ្នែកខាងក្រោម៖

Blender
   ផ្នែកនេះបង្ហាញកំណែ Blender ព័ត៌មានលម្អិតអំពីការកំណត់រចនាសម្ព័ន្ធនៃ build
   និងផ្លូវដែល Blender កំពុងដំណើរការ។
Python
   កំណែ និងផ្លូវនៃការដំឡើង Python របស់អ្នក។
Directories
   ផ្លូវដែលប្រើសម្រាប់ស្គ្រីប ឯកសារទិន្នន័យ preset និងឯកសារបណ្ដោះអាសន្ន។

   ថតទាំងនោះត្រូវបានកំណត់ដោយប្រើកម្មវិធីកែសម្រួល
   `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/file_paths.html>`__។
FFmpeg
   កំណែនៃសមាសភាគ និង codec របស់ FFmpeg ដែលបានដំឡើង។
Other Libraries
   កំណែនៃបណ្ណាល័យផ្សេងទៀតដែល Blender ប្រើ ដូចជា OpenColorIO, Alembic, USD ជាដើម។
GPU
   បង្ហាញអ្នកផលិត GPU កំណែ និងសមត្ថភាពនៃផ្នែករឹង និង driver របស់អ្នក។
Implementation Dependent GPU Limits
   ដែនកំណត់ជាក់លាក់លើអនុគមន៍ GPU ដែលពាក់ព័ន្ធនឹងរបៀបដែល Blender កំណែបច្ចុប្បន្ន
   ត្រូវបាន compile។
Cycles
   សំណុំសេចក្ដីណែនាំ (instruction set) និងសមត្ថភាពនៃឧបករណ៍ render ផ្នែករឹងនីមួយៗ
   ដែលអាចប្រើបានជាមួយ Cycles។
Enabled Add-Ons
   រាយបញ្ជី add-on ដែលកំពុងប្រើ ព្រមទាំងកំណែ និងផ្លូវរបស់វា។
