#########################
  អំពី Blender
#########################

Blender គឺជាកញ្ចប់ឧបករណ៍បង្កើតស្នាដៃ 3D ឥតគិតថ្លៃ និងមានប្រភពបើកចំហ (free and open-source)។
វាគាំទ្រដំណើរការ 3D ទាំងមូល៖ ការបង្កើតម៉ូដែល (modeling) ការបង្កើតឆ្អឹង (rigging) ចលនា (animation)
ការក្លែងធ្វើ (simulation) ការបង្កើតរូបភាព (rendering) ការផ្សំរូបភាព (compositing)
ការតាមដានចលនា (motion tracking) និងការកាត់តវីដេអូ។

Blender ផ្ដល់បទពិសោធន៍ស៊ីសង្វាក់គ្នានៅលើប្រព័ន្ធប្រតិបត្តិការ Linux, macOS និង Windows តាមរយៈ OpenGL។

.. figure:: /images/getting-started_about_introduction_screenshot.jpg


តើនរណាខ្លះប្រើ Blender?
=========================

Blender មានឧបករណ៍យ៉ាងសម្បូរបែប ដែលធ្វើឱ្យវាសាកសមនឹងការផលិតមេឌៀស្ទើរតែគ្រប់ប្រភេទ។
អ្នកជំនាញ អ្នកស្ម័គ្រចិត្ត និងស្ទូឌីយោជុំវិញពិភពលោកប្រើវាដើម្បីបង្កើតចលនា ទ្រព្យសម្រាប់ហ្គេម
ក្រាហ្វិកចលនា (motion graphics) កម្មវិធីទូរទស្សន៍ សិល្បៈគំនិត (concept art) ការរៀបចំសាច់រឿង
(story-boarding) ពាណិជ្ជកម្ម និងភាពយន្តខ្នាតធំ។

សូមមើលទំព័រ `User Stories <https://www.blender.org/get-involved/user-stories/>`__
នៅលើគេហទំព័រ Blender សម្រាប់ឧទាហរណ៍បន្ថែម។


មុខងារសំខាន់ៗ
===============

- Blender ជាកញ្ចប់ឧបករណ៍បង្កើតមាតិកា 3D ដែលរួមបញ្ចូលគ្នាពេញលេញ ដោយផ្ដល់ឧបករណ៍ចាំបាច់យ៉ាងទូលំទូលាយ
  រួមមាន
  `Modeling <https://docs.blender.org/manual/en/5.2/modeling/introduction.html>`__,
  `Rendering <https://docs.blender.org/manual/en/5.2/render/introduction.html>`__,
  `Animation & Rigging <https://docs.blender.org/manual/en/5.2/animation/introduction.html>`__,
  `Video Editing <https://docs.blender.org/manual/en/5.2/video_editing/index.html>`__,
  `VFX <https://docs.blender.org/manual/en/5.2/movie_clip/index.html>`__,
  `Compositing <https://docs.blender.org/manual/en/5.2/compositing/introduction.html>`__,
  `Texturing <https://docs.blender.org/manual/en/5.2/editors/uv/introduction.html>`__
  និង `Simulations <https://docs.blender.org/manual/en/5.2/physics/introduction.html>`__ ជាច្រើនប្រភេទ។
- វាដំណើរការបានលើគ្រប់ប្រព័ន្ធ (cross platform) ដោយមានចំណុចប្រទាក់ OpenGL
  ដែលដូចគ្នានៅលើគ្រប់ប្រព័ន្ធធំៗ (ហើយអាចប្ដូរតាមបំណងបានដោយស្គ្រីប Python)។
- វាមានស្ថាបត្យកម្ម 3D គុណភាពខ្ពស់ ដែលអនុញ្ញាតឱ្យមានលំហូរការងារបង្កើតយ៉ាងរហ័ស និងមានប្រសិទ្ធភាព។
- វាមានការគាំទ្រពីសហគមន៍ដែលសកម្ម។ សូមមើល `blender.org/community
  <https://www.blender.org/community>`__ សម្រាប់បញ្ជីគេហទំព័រយ៉ាងលម្អិត។
- វាអាចដំឡើង និងដំណើរការពីថតណាមួយក៏បាន ដោយមិនចាំបាច់កែប្រែប្រព័ន្ធ។

អ្នកអាចទាញយក Blender កំណែថ្មីបំផុតបាន `នៅទីនេះ <https://www.blender.org/download/>`__។

.. figure:: /images/getting-started_about_introduction_postprocessing.jpg

   រូបភាពដែលបាន render កំពុងត្រូវបានកែច្នៃក្រោយការ render (post-processing)។

Blender អាចធ្វើកិច្ចការបានយ៉ាងច្រើន ហើយវាអាចហាក់ដូចជាពិបាកនៅពេលចាប់ផ្ដើមដំបូង។
ប៉ុន្តែដោយមានការតាំងចិត្តបន្តិច និងសម្ភារៈសិក្សាត្រឹមត្រូវ អ្នកអាចស្គាល់ Blender
បានបន្ទាប់ពីការអនុវត្តពីរបីម៉ោង។

សៀវភៅណែនាំនេះគឺជាការចាប់ផ្ដើមដ៏ល្អ ទោះបីជាវាដើរតួជាឯកសារយោងច្រើនជាងក៏ដោយ។
ក៏មានវីដេអូបង្រៀនតាមអនឡាញជាច្រើនពីគេហទំព័រឯកទេសផងដែរ។

ទោះបីជា Blender អាចធ្វើអ្វីបានច្រើនក៏ដោយ វានៅតែជាឧបករណ៍មួយ។
សិល្បករដ៏អស្ចារ្យមិនបង្កើតស្នាដៃល្អដោយគ្រាន់តែចុចប៊ូតុង ឬប្រើជក់នោះទេ
ប៉ុន្តែដោយការសិក្សា និងអនុវត្តលើមុខវិជ្ជាដូចជា កាយវិភាគសាស្ត្រមនុស្ស ការរៀបចំសមាសភាព (composition)
ការបំភ្លឺ គោលការណ៍ចលនា ជាដើម។

កម្មវិធីបង្កើតស្នាដៃ 3D ដូចជា Blender មានភាពស្មុគស្មាញផ្នែកបច្ចេកទេស និងពាក្យបច្ចេកទេសបន្ថែម
ដែលពាក់ព័ន្ធនឹងបច្ចេកវិទ្យាមូលដ្ឋាន។ ពាក្យដូចជា UV map, material, shader, mesh និង «subdivs»
គឺជាភាសារបស់សិល្បករឌីជីថល ហើយការយល់ដឹងអំពីវា ទោះបីជាក្នុងកម្រិតទូទៅក៏ដោយ
នឹងជួយឱ្យអ្នកប្រើ Blender បានល្អបំផុត។

ដូច្នេះសូមបន្តអានសៀវភៅណែនាំនេះ សិក្សាពីឧបករណ៍ដ៏អស្ចារ្យដែល Blender មាន
ហើយបើកចិត្តទូលាយចំពោះផ្នែកសិល្បៈ និងបច្ចេកវិទ្យាផ្សេងទៀត — ហើយអ្នកក៏អាចក្លាយជាសិល្បករដ៏អស្ចារ្យដែរ។
