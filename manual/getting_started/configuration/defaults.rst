.. _splash-quick-start:

#############################
  ការកំណត់លំនាំដើម (Defaults)
#############################

នៅពេលអ្នកបើក Blender ជាលើកដំបូង ឬធ្វើបច្ចុប្បន្នភាពទៅកំណែថ្មី
តំបន់អន្តរកម្មរបស់ :doc:`អេក្រង់ចាប់ផ្ដើម (Splash Screen) </interface/window_system/splash>`
ត្រូវបានជំនួសដោយចំណូលចិត្តដំបូងមួយចំនួន ដើម្បីកំណត់ពីរបៀបដែលអ្នកធ្វើអន្តរកម្មជាមួយ Blender។

.. figure:: /images/getting-started_configuration_defaults_preferences.png

   ផ្ទាំងចំណូលចិត្តដំបូង។


.. note::

   ជម្រើសទាំងនេះអាចត្រូវបានផ្លាស់ប្ដូរជានិច្ចនៅពេលក្រោយក្នុង
   `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/index.html>`__។


ការនាំចូលចំណូលចិត្តពីកំណែមុន
==============================

ការជ្រើសរើសជម្រើសនេះនឹងចម្លងចំណូលចិត្តពី Blender កំណែចាស់។
ការធ្វើបែបនេះនឹងចម្លងចំណូលចិត្ត និងឯកសារចាប់ផ្ដើម (startup file) ពី Blender កំណែមុន ហើយផ្ទុកវា។
នេះនឹងរួមបញ្ចូលទាំង add-on និង extension ដែលបានដំឡើង។

ចំណូលចិត្តត្រូវការនាំចូលពីកំណែមុន ព្រោះឯកសារកំណត់រចនាសម្ព័ន្ធនៃ Blender កំណែនីមួយៗ
ត្រូវបានរក្សាទុកក្នុងថតដាច់ដោយឡែក។ សូមយោងទៅទំព័រ
`Blender Directory Layout <https://docs.blender.org/manual/en/5.2/advanced/blender_directory_layout.html>`__
សម្រាប់ទីតាំងនៃថតទាំងនេះ។

ប្រសិនបើអ្នកចង់ចាប់ផ្ដើមជាថ្មីជាមួយកំណែថ្មី សូមបន្តទៅ `ការបង្កើតចំណូលចិត្តថ្មី`_។

.. note::

   Add-on និង extension ខ្លះរបស់ Blender កំណែមុនអាចមិនឆបគ្នានឹង Blender កំណែថ្មីទេ
   ហើយការជ្រើសរើសជម្រើសនេះអាចនាំឱ្យមានកំហុសនៅពេលចាប់ផ្ដើម។
   ប្រសិនបើវាកើតឡើង ជំហានដំបូងដែលណែនាំគឺព្យាយាម `ការផ្ទុកការកំណត់រោងចក្រ`_។


ការបង្កើតចំណូលចិត្តថ្មី
========================

Language
   ភាសាដែលប្រើក្នុងចំណុចប្រទាក់អ្នកប្រើ។ បញ្ជីនេះត្រូវបានបំបែកជាក្រុម
   ដោយផ្អែកលើកម្រិតពេញលេញនៃការបកប្រែ។ ចំណូលចិត្តភាសាបន្ថែមអាចកំណត់បានក្នុង
   `Translation Preferences
   <https://docs.blender.org/manual/en/5.2/editors/preferences/interface.html#prefs-interface-translation>`__។

Theme
   ជ្រើសរើសរវាងរូបរាង (theme) ភ្លឺ ឬងងឹតសម្រាប់ Blender។ រូបរាងអាចប្ដូរតាមបំណងបានបន្ថែម
   ក្នុង `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/themes.html>`__។
   រូបរាងបន្ថែមអាចដំឡើងបានដោយចូលទៅកាន់
   `Blender Extensions Platform <https://extensions.blender.org/>`__។
   នេះជាជម្រើស ហើយនឹងត្រូវការការតភ្ជាប់អ៊ីនធឺណិត។

Keymap
   ការកំណត់ជាមុន (preset) សម្រាប់ `keymap <https://docs.blender.org/manual/en/5.2/editors/preferences/keymap.html>`__
   លំនាំដើមរបស់ Blender។ ចំណាំថា សៀវភៅណែនាំនេះសន្មតថាអ្នកប្រើ keymap «Blender» លំនាំដើម។

   :Blender:
      នេះគឺជា keymap លំនាំដើម។ អានបន្ថែមអំពី keymap នេះ
      `នៅទីនេះ <https://docs.blender.org/manual/en/5.2/interface/keymap/blender_default.html>`__។
   :Blender 2.7x:
      Keymap នេះមានបំណងឱ្យត្រូវនឹងកំណែ Blender ស៊េរីចាស់
      និងរចនាឡើងសម្រាប់អ្នកដែលធ្វើឱ្យប្រសើរឡើង ប៉ុន្តែមិនចង់រៀន keymap ថ្មី។
   :Industry Compatible:
      Keymap នេះមានបំណងឱ្យត្រូវនឹងកម្មវិធីបង្កើតពាណិជ្ជកម្មទូទៅ
      និងសម្រាប់អ្នកដែលប្រើកម្មវិធីបែបនេះច្រើនផ្សេងគ្នា។ អានបន្ថែមអំពី keymap នេះ
      `នៅទីនេះ <https://docs.blender.org/manual/en/5.2/interface/keymap/industry_compatible.html>`__។

Mouse Select
   គ្រប់គ្រងថាតើប៊ូតុងកណ្ដុរណា — ស្ដាំ ឬឆ្វេង — ត្រូវបានប្រើដើម្បីជ្រើសរើសធាតុក្នុង Blender។
   លំនាំដើមគឺប្រើប៊ូតុងឆ្វេងសម្រាប់ការជ្រើសរើស។

Spacebar Action
   គ្រប់គ្រងសកម្មភាពរបស់ :kbd:`Spacebar`។
   ទាំងនេះ និងផ្លូវកាត់ផ្សេងទៀតអាចត្រូវបានកែប្រែក្នុង
   `ចំណូលចិត្ត keymap <https://docs.blender.org/manual/en/5.2/editors/preferences/keymap.html>`__។

   :Play:
      ចាប់ផ្ដើម/បញ្ឈប់ `ការចាក់ចលនា (animation playback)
      <https://docs.blender.org/manual/en/5.2/animation/index.html>`__។
      ជម្រើសនេះល្អសម្រាប់ការងារចលនា ឬការកាត់តវីដេអូ។
   :Tools:
      បើករបារឧបករណ៍ (Toolbar) នៅខាងក្រោមទ្រនិច ដើម្បីប្ដូរឧបករណ៍សកម្មយ៉ាងរហ័ស។
      ជម្រើសនេះល្អប្រសិនបើធ្វើការងារ modeling ឬ rigging ច្រើន។
   :Search:
      បើក :ref:`Menu Search <bpy.ops.wm.search_menu>`។
      ជម្រើសនេះល្អសម្រាប់អ្នកដែលថ្មីនឹង Blender និងមិនទាន់ស្គាល់ម៉ឺនុយ និងផ្លូវកាត់របស់វា។

Save New Preferences
   រក្សាទុកចំណូលចិត្តដែលបានកំណត់ខាងលើ ហើយបើក :doc:`អេក្រង់ចាប់ផ្ដើម </interface/window_system/splash>`
   ធម្មតា។


ការរក្សាទុកការកំណត់លំនាំដើម
============================

ចំណូលចិត្តត្រូវបានរក្សាទុកដោយស្វ័យប្រវត្តិនៅពេលផ្លាស់ប្ដូរ។
ឥរិយាបថនេះអាចផ្លាស់ប្ដូរបានដោយអនុវត្តតាមការណែនាំក្រោម
:ref:`ការរក្សាទុកចំណូលចិត្តដោយស្វ័យប្រវត្តិ <autosave-preferences>`។

ការផ្លាស់ប្ដូរឯកសារចាប់ផ្ដើមលំនាំដើមអាចធ្វើបានតាម
:menuselection:`File --> Defaults --> Save Startup File`។
សូមមើល :ref:`ឯកសារចាប់ផ្ដើម (Startup File) <startup-file>`។

មានពីរកន្លែងដែលការកំណត់លំនាំដើមរបស់ Blender ត្រូវបានរក្សាទុក៖

Preferences
   ឯកសារ `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/introduction.html#prefs-menu>`__
   រក្សាទុក keymap, add-on, រូបរាង (theme) និងជម្រើសផ្សេងទៀត។
Startup File
   :ref:`ឯកសារចាប់ផ្ដើម (Startup File) <startup-file>` រក្សាទុកឆាក និងការរៀបចំចំណុចប្រទាក់
   ដែលបង្ហាញនៅពេលចាប់ផ្ដើម និងនៅពេលបង្កើតឯកសារថ្មី (:menuselection:`File --> New`)។


ការផ្ទុកការកំណត់រោងចក្រ
========================

អ្នកអាចត្រឡប់ការប្ដូរតាមបំណងរបស់អ្នកទៅការកំណត់លំនាំដើមរបស់ Blender៖

Preferences
   Load Factory Settings របស់
   `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/introduction.html#prefs-menu>`__។
Startup File និង Preferences
   :menuselection:`File --> Defaults --> Load Factory Settings`។

.. note::

   បន្ទាប់ពីផ្ទុកការកំណត់រោងចក្រ ចំណូលចិត្តនឹងមិនត្រូវបានរក្សាទុកដោយស្វ័យប្រវត្តិទេ។

   សូមមើល `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/introduction.html#prefs-menu>`__
   សម្រាប់ព័ត៌មានលម្អិត។
