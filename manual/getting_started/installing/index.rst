#############################################
  ការដំឡើង Blender (Installing Blender)
#############################################

Blender ត្រូវបានចេញផ្សាយប្រហែលរៀងរាល់បីខែម្ដង។ អ្នកអាចតាមដានការផ្លាស់ប្ដូរថ្មីៗ
តាមរយៈ `កំណត់ត្រាការចេញផ្សាយ (release notes) <https://www.blender.org/download/releases/>`__។


តម្រូវការប្រព័ន្ធ
==================

Blender អាចទាញយកបានសម្រាប់ Windows, macOS និង Linux។ សូមពិនិត្យជានិច្ចថា
កម្មវិធីបញ្ជាក្រាហ្វិក (graphics driver) របស់អ្នកទាន់សម័យ និងថា OpenGL ត្រូវបានគាំទ្រត្រឹមត្រូវ។
Blender មាន `តម្រូវការអប្បបរមា និងតម្រូវការណែនាំ
<https://www.blender.org/download/requirements/>`__ មួយចំនួន
ដូច្នេះសូមប្រាកដថាវាត្រូវបានបំពេញ មុនពេលព្យាយាមដំឡើង Blender។

ការគាំទ្រសម្រាប់ផ្នែករឹងផ្សេងទៀត ដូចជា tablet គូររូប និងកណ្ដុរ 3D ត្រូវបានពន្យល់នៅផ្នែកក្រោយ
ក្នុង :doc:`ការកំណត់ផ្នែករឹង </getting_started/configuration/hardware>`។


ទាញយក Blender
===============

Blender ផ្ដល់កញ្ចប់ binary ផ្សេងៗគ្នាជាច្រើន ដើម្បីជ្រើសរើសតាមកម្រិតស្ថិរភាពរបស់វា។
កញ្ចប់នីមួយៗមានការជួបជុំគ្នារវាងមុខងារថ្មីបំផុត និងស្ថិរភាព។ កញ្ចប់ដែលសាកសមនឹងអ្នក
អាស្រ័យលើតម្រូវការរបស់អ្នកលើចំណុចទាំងពីរនេះ។ ឧទាហរណ៍ ស្ទូឌីយោមួយអាចចង់បាន
*ការគាំទ្ររយៈពេលវែង (long-term support)* ខណៈដែលអ្នកប្រើប្រាស់សម្រាប់ចំណង់ចំណូលចិត្ត
អាចចង់បានមុខងារថ្មីៗ រីឯអ្នកខ្លះទៀតគ្រាន់តែចង់សាកល្បងមុខងារដែលនឹងមកដល់។
កញ្ចប់នីមួយៗដែលបានពណ៌នាខាងក្រោមមានអ្វីមួយសមស្របសម្រាប់មនុស្សគ្រប់គ្នា។

`Stable Release <https://www.blender.org/download/>`__
   កញ្ចប់ដែលមានមុខងារថ្មីបំផុត និងត្រូវបានចាត់ទុកថាមានស្ថិរភាព ដោយគ្មានការថយក្រោយ (regression)។
   កំណែ stable ថ្មីមានប្រហែលរៀងរាល់បីខែម្ដង។

`Long-term Support <https://www.blender.org/download/lts/>`__
   កញ្ចប់ដែលរចនាឡើងសម្រាប់គម្រោងរយៈពេលវែង ដែលត្រូវការ Blender កំណែមានស្ថិរភាពខ្ពស់។
   ការចេញផ្សាយ :abbr:`LTS (Long-Term-Support)` ត្រូវបានគាំទ្ររយៈពេលពីរឆ្នាំ
   ហើយនឹងមិនមានមុខងារថ្មី ការផ្លាស់ប្ដូរ API ឬការធ្វើឱ្យប្រសើរឡើងទេ។
   កំណែ long-term support ថ្មីមានជារៀងរាល់ឆ្នាំ។ *ការចេញផ្សាយ LTS ទាំងនេះនឹងមាន
   patch តូចៗជាប្រចាំ (ដូចជា 4.2.6) ដែលធ្វើឱ្យស្ថិរភាពប្រសើរឡើង ឬកែកំហុសធ្ងន់ធ្ងរ។*

`Daily Builds <https://builder.blender.org/download/daily/>`__
   កញ្ចប់ដែលធ្វើបច្ចុប្បន្នភាពជារៀងរាល់ថ្ងៃ ដើម្បីរួមបញ្ចូលការផ្លាស់ប្ដូរថ្មីបំផុតក្នុងការអភិវឌ្ឍ។
   កំណែទាំងនេះត្រូវបាន build ដោយស្វ័យប្រវត្តិតាមកាលវិភាគ។
   វាមិនត្រូវបានសាកល្បងយ៉ាងហ្មត់ចត់ដូចប្រភេទចេញផ្សាយខាងលើទេ ហើយអាចខូច ឬគាំង។
   Build ដែលសម្គាល់ថា **Alpha** នៅតែកំពុងមានការផ្លាស់ប្ដូរធំៗ និងការបន្ថែមមុខងារ
   ខណៈដែលអ្វីដែលសម្គាល់ថា **Beta** មានមុខងារគ្រប់គ្រាន់ហើយ
   និងកំពុងអភិវឌ្ឍដើម្បីធ្វើឱ្យល្អឡើង និងមានស្ថិរភាព។

   ស្ថិរភាពអាចត្រូវបានរំពឹងថានឹងកើនឡើងពី Alpha ទៅ Beta ទៅ Release Candidate (RC)
   និងទៅការចេញផ្សាយចុងក្រោយ។

`Build from Source <https://developer.blender.org/docs/handbook/building_blender/>`__
   កូដប្រភពរបស់ Blender មានដោយឥតគិតថ្លៃ សម្រាប់យោង ឬសម្រាប់ build និងប្រើ។
   ទោះបីជាអ្នកប្រើប្រាស់ធម្មតា **មិន** ត្រូវបានរំពឹងថានឹង compile Blender ក៏ដោយ
   វាមានអត្ថប្រយោជន៍៖

   - Blender ទាន់សម័យជានិច្ច។
   - វាអនុញ្ញាតឱ្យចូលដំណើរការកំណែ ឬសាខាណាមួយក៏បាន ដែលមុខងារកំពុងត្រូវបានអភិវឌ្ឍ។
   - វាអាចប្ដូរតាមបំណងបានដោយសេរី។
   - អ្នកប្រើដែលចង់ដឹងអាចមើលកូដប្រភព និងធ្វើការកែប្រែតូចៗ ដើម្បីមើលលទ្ធផល
     និងយល់កាន់តែច្បាស់ពីរបៀបដែល Blender ដំណើរការ។

នីតិវិធីសម្រាប់ដំឡើង binary — ទោះជាការចេញផ្សាយ stable ថ្មីបំផុត ឬ daily build — គឺដូចគ្នា។
សូមអនុវត្តតាមជំហានសម្រាប់ប្រព័ន្ធរបស់អ្នកដែលបានរាយខាងក្រោម។

.. note::

   Blender ត្រូវបានរចនាឡើងដោយមិនត្រូវការការតភ្ជាប់អ៊ីនធឺណិត ដូច្នេះវាមិនមានប្រព័ន្ធ
   ធ្វើបច្ចុប្បន្នភាពក្នុងកម្មវិធីទេ។ នេះមានន័យថាអ្នកត្រូវធ្វើបច្ចុប្បន្នភាព Blender ដោយខ្លួនឯង
   ដោយអនុវត្តតាមជំហានធ្វើឱ្យប្រសើរឡើងជាក់លាក់សម្រាប់ប្រព័ន្ធ ដែលបានពណ៌នាក្នុងផ្នែកខាងក្រោម។
