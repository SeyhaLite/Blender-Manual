###########################################
  ការដំឡើងលើ macOS
###########################################

សូមពិនិត្យមើលទំព័រ :doc:`ការទាញយក Blender </getting_started/installing/index>`
ដើម្បីរកតម្រូវការអប្បបរមា និងកំណែផ្សេងៗដែលមានសម្រាប់ Blender (ប្រសិនបើអ្នកមិនទាន់បានធ្វើ)។

.. important::

   Blender 5.0 និងកំណែបន្ទាប់ គាំទ្រតែ Mac ដែលមាន Apple silicon ប៉ុណ្ណោះ។
   សម្រាប់ព័ត៌មានបន្ថែម សូមមើល `Deprecation and removal of macOS Intel builds in Blender 5.0
   <https://devtalk.blender.org/t/deprecation-and-removal-of-macos-intel-builds-in-blender-5-0/>`__។


ដំឡើងពី DMG
==============

Blender សម្រាប់ macOS ត្រូវបានចែកចាយជារូបភាពថាស (disk image ឬឯកសារ ``.dmg``)។
ដើម្បី mount រូបភាពថាស សូមចុចទ្វេដងលើឯកសារ ``.dmg``។
បន្ទាប់មកអូស ``Blender.app`` ទៅក្នុងថត Applications។

អាស្រ័យលើចំណូលចិត្ត Security and Privacy របស់ Mac អ្នក macOS នឹងសុំការយល់ព្រមពីអ្នក
មុនពេលបើក Blender ជាលើកដំបូង។

ដើម្បីធ្វើឱ្យការដំឡើង និងការកំណត់ពេញលេញដាច់ដោយឡែក (self-contained) សូមរៀបចំ
`Portable Installation <https://docs.blender.org/manual/en/5.2/advanced/blender_directory_layout.html#portable-installation>`__។


ការធ្វើបច្ចុប្បន្នភាពលើ macOS
==============================

នៅលើ macOS មានវិធីសំខាន់មួយដើម្បីធ្វើបច្ចុប្បន្នភាព Blender។ ផ្នែកនេះពណ៌នាអំពីវិធីសាស្ត្រនោះ។


ធ្វើបច្ចុប្បន្នភាពពី DMG
-------------------------

នៅពេលដែលកំណែធ្វើបច្ចុប្បន្នភាពរបស់ Blender ត្រូវបានចេញផ្សាយ វាអាចត្រូវបានទាញយកដោយផ្ទាល់ពី
`គេហទំព័រ Blender <https://www.blender.org/download/>`__។
ដំឡើងកំណែថ្មីដោយសរសេរជាន់លើ ``Blender.app`` បច្ចុប្បន្ននៅក្នុងថត Applications។
អ្នកអាចប្ដូរឈ្មោះ ``Blender.app`` ឬដាក់វានៅក្នុងថតផ្សេង ដើម្បីមានកំណែច្រើនក្នុងពេលតែមួយ។
