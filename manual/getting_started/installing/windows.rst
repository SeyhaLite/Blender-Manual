#############################################
  ការដំឡើងលើ Windows
#############################################

សូមពិនិត្យមើលទំព័រ :doc:`ការទាញយក Blender </getting_started/installing/index>`
ដើម្បីរកតម្រូវការអប្បបរមា និងកំណែផ្សេងៗដែលមានសម្រាប់ Blender (ប្រសិនបើអ្នកមិនទាន់បានធ្វើ)។

ទាញយកឯកសារ zip ឬឯកសារដំឡើងរបស់ Windows (Windows Installer File)។

.. important::

   Blender គាំទ្រទាំងស្ថាបត្យកម្ម x64 និង arm64 នៅលើ Windows។
   សូមប្រាកដថាអ្នកទាញយកកំណែដែលឆបគ្នានឹងស្ថាបត្យកម្ម CPU របស់អ្នក។


ដំឡើងពីឯកសារ Windows Installer
==================================

កម្មវិធីដំឡើងរបស់ Windows នឹងអនុញ្ញាតឱ្យអ្នកជ្រើសរើសថតដំឡើង
ហើយនឹងបង្កើតធាតុមួយនៅក្នុង Start menu ព្រមទាំងភ្ជាប់ឯកសារ ``.blend`` ជាមួយ Blender។
វាត្រូវការសិទ្ធិរដ្ឋបាល (administrator rights)។


ដំឡើងពី Zip
==============

នៅពេលជ្រើសរើសឯកសារ zip អ្នកត្រូវពន្លា (extract) Blender ដោយដៃទៅកាន់ថតដែលចង់បាន
ហើយអ្នកអាចចុចទ្វេដងលើឯកសារដែលដំណើរការបាន (executable) ដើម្បីបើក Blender។

ធាតុ Start menu នឹងមិនត្រូវបានបង្កើតទេ ហើយការភ្ជាប់ឯកសារ ``.blend`` ក៏នឹងមិនត្រូវបានចុះបញ្ជីដែរ
ប៉ុន្តែក៏មិនត្រូវការសិទ្ធិរដ្ឋបាលដែរ។ អ្នកអាចចុះបញ្ជីការភ្ជាប់ឯកសារដោយដៃ
ដោយចុចលើ :ref:`Register <bpy.ops.preferences.associate_blend>` នៅលើផ្ទាំង *System*
នៃ `Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/system.html>`__។
ជាជម្រើសផ្សេង អ្នកអាចដំណើរការ ``blender -r`` ពី
`បន្ទាត់ពាក្យបញ្ជា (Command Line) <https://docs.blender.org/manual/en/5.2/advanced/command_line/arguments.html>`__។

ដើម្បីធ្វើឱ្យការដំឡើង និងការកំណត់ពេញលេញដាច់ដោយឡែក (self-contained)
សូមរៀបចំ
`Portable Installation <https://docs.blender.org/manual/en/5.2/advanced/blender_directory_layout.html#portable-installation>`__។


ដំឡើងពី Microsoft Store
==========================

Blender អាចត្រូវបានដំឡើងពី Microsoft Store ដោយស្វែងរក «Blender» នៅក្នុង Microsoft Store
ហើយដំឡើងវា។

បន្ទាប់ពីដំឡើង Blender អាចត្រូវបានបើកពី Windows Start menu។


ការធ្វើបច្ចុប្បន្នភាពលើ Windows
================================

នៅលើ Windows មានវិធីពីរបីយ៉ាងដើម្បីធ្វើបច្ចុប្បន្នភាព Blender។
ផ្នែកនេះពណ៌នាអំពីវិធីសាស្ត្រដែលពេញនិយមបំផុត។


ធ្វើបច្ចុប្បន្នភាពពីឯកសារ Windows Installer
------------------------------------------------

នៅពេលដែលកំណែធ្វើបច្ចុប្បន្នភាពរបស់ Blender ត្រូវបានចេញផ្សាយ វាអាចត្រូវបានទាញយកដោយផ្ទាល់ពី
`គេហទំព័រ Blender <https://www.blender.org/download/>`__។
បន្ទាប់មកអាចដំណើរការកម្មវិធីដំឡើងរបស់ Windows ដើម្បីដំឡើង Blender កំណែថ្មី។
ដើម្បីដក Blender កំណែដែលបានដំឡើងពីមុន សូមប្រើការកំណត់របស់ Windows ឬ Control Panel
ដើម្បី uninstall កំណែដែលចង់ដក។


ធ្វើបច្ចុប្បន្នភាពពី Zip
--------------------------

នៅពេលដែលកំណែធ្វើបច្ចុប្បន្នភាពរបស់ Blender ត្រូវបានចេញផ្សាយ វាអាចត្រូវបានទាញយកដោយផ្ទាល់ពី
`គេហទំព័រ Blender <https://www.blender.org/download/>`__ ហើយពន្លាទៅកាន់ថតដែលចង់បាន
ដែលអ្នកអាចចុចទ្វេដងលើឯកសារ executable ដើម្បីដំណើរការ Blender។
សម្រាប់ព័ត៌មានបន្ថែមអំពីការបង្កើត Blender កំណែ portable សូមមើលផ្នែក `ដំឡើងពី Zip`_។

ចំណាំថា អ្នកមិនចាំបាច់សរសេរជាន់លើការដំឡើង Blender ដែលមានស្រាប់របស់អ្នកទេ។
វាអាចធ្វើទៅបានយ៉ាងពេញលេញក្នុងការដំឡើងកំណែច្រើននៅជាប់គ្នា។


ធ្វើបច្ចុប្បន្នភាពពី Microsoft Store
---------------------------------------

នៅពេលដែលមានកំណែធ្វើបច្ចុប្បន្នភាពរបស់ Blender នៅលើ Microsoft Store
វានឹងត្រូវបានទាញយក និងដំឡើងដោយស្វ័យប្រវត្តិ។
