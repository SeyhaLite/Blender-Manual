###########################################
  ការដំឡើងលើ Linux
###########################################

សូមពិនិត្យមើលទំព័រ :doc:`ការទាញយក Blender </getting_started/installing/index>`
ដើម្បីរកតម្រូវការអប្បបរមា និងកំណែផ្សេងៗដែលមានសម្រាប់ Blender (ប្រសិនបើអ្នកមិនទាន់បានធ្វើ)។


ដំឡើងពី blender.org
=====================

ទាញយក Blender កំណែ Linux សម្រាប់ស្ថាបត្យកម្មរបស់អ្នក ហើយពន្លាឯកសារទៅកាន់ទីតាំងដែលចង់បាន
(ឧទាហរណ៍ ``~/software`` ឬ ``/usr/local``)។

ឥឡូវ Blender អាចត្រូវបានបើកដោយចុចទ្វេដងលើឯកសារ executable។

នៅពេលប្រើវិធីដំឡើងនេះ អ្នកអាចដំឡើង Blender បានច្រើនកំណែ។

ដើម្បីងាយស្រួលចូលប្រើ អ្នកប្រហែលជាចង់បន្ថែមធាតុម៉ឺនុយ និងបង្កើតការភ្ជាប់ឯកសារ ``.blend``
សម្រាប់កម្មវិធីរុករកឯកសារ (file-browser)។ នេះអាចធ្វើបានដោយ
:ref:`ការចុះបញ្ជី Blender <bpy.ops.preferences.associate_blend>`។

ដើម្បីធ្វើឱ្យការដំឡើង និងការកំណត់ពេញលេញដាច់ដោយឡែក (self-contained) សូមរៀបចំ
`Portable Installation <https://docs.blender.org/manual/en/5.2/advanced/blender_directory_layout.html#portable-installation>`__។


ដំឡើងពីកម្មវិធីគ្រប់គ្រងកញ្ចប់ (Package Manager)
====================================================

ការចែកចាយ Linux (distribution) ខ្លះអាចមានកញ្ចប់ជាក់លាក់សម្រាប់ Blender នៅក្នុងឃ្លាំងរបស់ខ្លួន។

ការដំឡើង Blender តាមរយៈយន្តការដើមរបស់ distribution ធានានូវភាពស៊ីសង្វាក់គ្នា
ជាមួយកញ្ចប់ផ្សេងទៀតនៅលើប្រព័ន្ធ និងអាចផ្ដល់មុខងារផ្សេងទៀត (ដែលកម្មវិធីគ្រប់គ្រងកញ្ចប់ផ្ដល់ឱ្យ)
ដូចជាការរាយបញ្ជីកញ្ចប់ ការជូនដំណឹងអំពីបច្ចុប្បន្នភាព និងការកំណត់ម៉ឺនុយដោយស្វ័យប្រវត្តិ។
ប៉ុន្តែសូមដឹងថា កញ្ចប់នោះអាចហួសសម័យធៀបនឹងការចេញផ្សាយផ្លូវការថ្មីបំផុត
ឬមិនរួមបញ្ចូលមុខងារខ្លះរបស់ Blender។ ឧទាហរណ៍ distribution ខ្លះមិន build Blender
ជាមួយការគាំទ្រ Cycles GPU rendering ទេ ដោយសារមូលហេតុអាជ្ញាបណ្ណ ឬមូលហេតុផ្សេងទៀត។

ប្រសិនបើមានកញ្ចប់ជាក់លាក់សម្រាប់ distribution របស់អ្នក អ្នកអាចជ្រើសរើសអ្វីដែលពេញចិត្ត
និងងាយស្រួលបំផុត។ បើមិនដូច្នោះទេ binary ផ្លូវការមាននៅ
`blender.org <https://www.blender.org/download/>`__។


ដំឡើងពី Snap
===============

`Snap <https://snapcraft.io/>`__ គឺជាកម្មវិធីគ្រប់គ្រងកញ្ចប់សកល ដែលរចនាឡើង
ដើម្បីដំណើរការលើ distribution ជាច្រើន។ ដោយសន្មតថា snap បានដំឡើងរួចហើយ
Blender អាចត្រូវបានដំឡើងតាមរយៈ snap ដោយ::

   snap install blender --classic

ការដំឡើងតាមវិធីនេះមានអត្ថប្រយោជន៍គឺ ការធ្វើបច្ចុប្បន្នភាព Blender ត្រូវបានដំឡើងដោយស្វ័យប្រវត្តិ។
Blender ពី Snap គួរតែមានការចែកចាយស៊ីសង្វាក់គ្នាជាងកម្មវិធីគ្រប់គ្រងកញ្ចប់នីមួយៗដាច់ដោយឡែក។


ដំណើរការពីស្ថានីយ (Terminal)
===============================

សូមមើល `ការបើកដំណើរការពីស្ថានីយ

ប្រព័ន្ធក្រាហ្វិក (X11 និង Wayland)
====================================

Blender គាំទ្រទាំង X11 និង Wayland។ សូមមើល :ref:`linux-windowing-environment` សម្រាប់ព័ត៌មានលម្អិត។


ការជៀសវាងជម្លោះ Alt-Mouse
============================

កម្មវិធីគ្រប់គ្រងបង្អួច (window manager) ខ្លះលំនាំដើមប្រើ :kbd:`Alt-LMB` និង :kbd:`Alt-RMB`
សម្រាប់ផ្លាស់ទី និងប្ដូរទំហំបង្អួច។

Blender ប្រើគ្រាប់ចុចទាំងនេះសម្រាប់ប្រតិបត្តិការផ្សេងៗ ជាពិសេស៖

- :ref:`Emulate 3 Button Mouse <bpy.types.PreferencesInput.use_mouse_emulate_3_button>`។
- :ref:`bpy.ops.mesh.loop_multi_select`។
- `ការផ្លាស់ប្ដូរលក្ខណសម្បត្តិច្រើនក្នុងពេលតែមួយ
  <https://docs.blender.org/manual/en/5.2/interface/keymap/blender_default.html#keymap-common-properties>`__។

ដើម្បីចូលដំណើរការមុខងារពេញលេញរបស់ Blender អ្នកអាចប្ដូរការកំណត់របស់ window manager
ទៅប្រើគ្រាប់ចុច *Meta* វិញ (ហៅផងដែរថាគ្រាប់ចុច *Super* ឬ *Windows*)៖

Gnome
   បញ្ចូលពាក្យបញ្ជាខាងក្រោមក្នុងបន្ទាត់ពាក្យបញ្ជា (មានប្រសិទ្ធភាពនៅការចូលបន្ទាប់)៖

   .. code-block:: sh

      gsettings set org.gnome.desktop.wm.preferences mouse-button-modifier '<Super>'

KDE
   :menuselection:`System Settings --> Window Management --> Window Behavior --> Window Actions`,
   ប្ដូរពីគ្រាប់ចុច 'Alt' ទៅគ្រាប់ចុច 'Meta'។


ការធ្វើបច្ចុប្បន្នភាពលើ Linux
===============================

នៅលើ Linux មានវិធីពីរយ៉ាងដើម្បីធ្វើបច្ចុប្បន្នភាព Blender។
ផ្នែកនេះពណ៌នាអំពីវិធីសាស្ត្រដែលពេញនិយមបំផុត។


ធ្វើបច្ចុប្បន្នភាពពី blender.org
----------------------------------

នៅពេលដែលកំណែធ្វើបច្ចុប្បន្នភាពរបស់ Blender ត្រូវបានចេញផ្សាយ វាអាចត្រូវបានទាញយកដោយផ្ទាល់ពី
`គេហទំព័រ Blender <https://www.blender.org/download/>`__ ហើយដំឡើងដោយប្រើជំហាន
ដែលបានពណ៌នាក្នុងផ្នែក `ដំឡើងពី blender.org`_។


ធ្វើបច្ចុប្បន្នភាពដោយកម្មវិធីគ្រប់គ្រងកញ្ចប់
----------------------------------------------

Distribution Linux ជាច្រើនមានកញ្ចប់សម្រាប់ Blender ដែលអាចដំឡើងបាន
ដោយប្រើកម្មវិធីគ្រប់គ្រងកញ្ចប់របស់ distribution។ បន្ទាប់ពីដំឡើង
Blender អាចត្រូវបានធ្វើបច្ចុប្បន្នភាពដោយប្រើជំហានដូចគ្នានឹងការធ្វើបច្ចុប្បន្នភាពកម្មវិធីផ្សេងទៀត។

   ទំព័រ :doc:`អេក្រង់ចាប់ផ្ដើម (Splash screen) </getting_started/configuration/defaults>`
   សម្រាប់ព័ត៌មានអំពីការនាំចូលការកំណត់ពី Blender កំណែមុន និងការកំណត់រហ័សផ្សេងទៀត។
