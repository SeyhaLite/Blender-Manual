.. _glossary:

##########################
  វចនានុក្រម (Glossary)
##########################

ទំព័រនេះផ្ដល់និយមន័យសម្រាប់ពាក្យបច្ចេកទេសដែលប្រើក្នុង Blender និងក្នុងសៀវភៅណែនាំនេះ។

.. admonition:: វិសាលភាព
   :class: note

   វចនានុក្រមនេះគ្របដណ្ដប់តែពាក្យដែលប្រើក្នុងផ្នែកដែល **បានបកប្រែរួច** ប៉ុណ្ណោះ
   ហើយនឹងត្រូវពង្រីកបន្ថែមតាមការបកប្រែផ្នែកថ្មីៗ។
   សម្រាប់វចនានុក្រមពេញលេញជាភាសាអង់គ្លេស សូមមើល
   `Glossary ផ្លូវការ <https://docs.blender.org/manual/en/5.2/glossary/index.html>`__។

ពាក្យនីមួយៗត្រូវបានចុះទាំងពាក្យអង់គ្លេស និងពាក្យខ្មែរ ដូច្នេះអ្នកអាចស្វែងរកបានទាំងពីរភាសា។
ឈ្មោះបច្ចេកទេសដើម (API, operator, property) ត្រូវបានរក្សាជាភាសាអង់គ្លេសជានិច្ច។

.. glossary::

   Active
   សកម្ម
      នៅពេលដែលធាតុច្រើនត្រូវបានជ្រើសរើស ធាតុដែលបានជ្រើសរើសចុងក្រោយនឹងក្លាយជាធាតុសកម្ម (active)។
      វាត្រូវបានប្រើក្នុងករណីដែលចំណុចប្រទាក់បង្ហាញជម្រើសសម្រាប់តែធាតុមួយក្នុងពេលតែមួយ។

   Add-on
   កម្មវិធីបន្ថែម
      ស្គ្រីប Python ដែលពង្រីកមុខងាររបស់ Blender។ អាចបើក ឬបិទបានក្នុង
      :menuselection:`Edit --> Preferences --> Add-ons`។

   API
      ចំណុចប្រទាក់កម្មវិធីកម្មវិធី (Application Programming Interface)។ ក្នុង Blender
      សំដៅលើ ``bpy`` — ម៉ូឌុល Python ដែលអនុញ្ញាតឱ្យសរសេរស្គ្រីបគ្រប់គ្រង Blender។

   Area
   តំបន់
      ផ្នែកមួយនៃបង្អួច Blender ដែលបង្ហាញកម្មវិធីកែសម្រួល (editor) មួយ។
      បង្អួចមួយអាចត្រូវបានបំបែកជាតំបន់ជាច្រើន។ សូមមើល :doc:`/interface/window_system/areas`។

   Armature
   ឆ្អឹង
      ប្រភេទវត្ថុមួយដែលមានឆ្អឹង (bone) សម្រាប់ធ្វើចលនាវត្ថុផ្សេង ជាពិសេសតួអង្គ។
      ប្រើក្នុងការ rig និង animation។

   Asset
   ទ្រព្យ
      ឯកសារ ឬ data-block ដែលបានសម្គាល់ថាអាចយកមកប្រើឡើងវិញបាន
      (ឧទាហរណ៍ ម៉ូដែល សម្ភារៈ ឬ brush) តាមរយៈ Asset Browser។

   Blend-file
   ឯកសារ ``.blend``
      ទម្រង់ឯកសារដើមរបស់ Blender ដែលផ្ទុកឆាក វត្ថុ និងការកំណត់ទាំងអស់។

   Collection
   ការប្រមូលផ្ដុំ
      វិធីរៀបចំវត្ថុជាក្រុមនៅក្នុងឆាកមួយ ដើម្បីគ្រប់គ្រងការមើលឃើញ និងការ render។

   Context Menu
   ម៉ឺនុយបរិបទ
      ម៉ឺនុយដែលលោតឡើងនៅកន្លែងទ្រនិច ជាធម្មតាដោយចុចប៊ូតុងកណ្ដុរស្ដាំ (:kbd:`RMB`)
      ហើយបង្ហាញជម្រើសដែលពាក់ព័ន្ធនឹងបរិបទបច្ចុប្បន្ន។

   Cursor
   ទ្រនិច
      សញ្ញាបង្ហាញទីតាំងនៅលើអេក្រង់។ ក្នុង Blender មានពីរប្រភេទសំខាន់៖
      ទ្រនិចកណ្ដុរ (mouse cursor) និង :term:`3D Cursor`។

   3D Cursor
   ទ្រនិច 3D
      ចំណុចយោងក្នុងលំហ 3D ដែលប្រើជាមជ្ឈមណ្ឌលសម្រាប់បង្កើតវត្ថុថ្មី បង្វិល ឬពង្រីក។

   Data-Block
   ប្លុកទិន្នន័យ
      ឯកតាទិន្នន័យមូលដ្ឋានរបស់ Blender (ឧទាហរណ៍ mesh, material, texture, scene)
      ដែលអាចមានឈ្មោះ អាចចែករំលែករវាងវត្ថុ និងអាចត្រូវបានរក្សាទុកក្នុងឯកសារ ``.blend``។

   Editor
   កម្មវិធីកែសម្រួល
      ផ្ទាំងធ្វើការមួយរបស់ Blender ដូចជា 3D Viewport, Outliner, Properties ឬ Node Editor។
      តំបន់ (area) នីមួយៗបង្ហាញកម្មវិធីកែសម្រួលមួយ។

   Edge
   ជ្រុង
      បន្ទាត់ដែលភ្ជាប់កំពូល (vertex) ពីរក្នុង mesh មួយ។

   Face
   មុខ
      ផ្ទៃដែលបិទជិតដោយជ្រុង (edge) បី ឬច្រើនក្នុង mesh មួយ។

   Geometry Nodes
      ប្រព័ន្ធ node សម្រាប់បង្កើត និងកែប្រែ geometry តាមរបៀប procedural
      (ដោយមិនកែដោយដៃលើ mesh)។

   Gizmo
      ធាតុគ្រប់គ្រងដែលអាចអូសបាននៅក្នុង viewport សម្រាប់ធ្វើប្រតិបត្តិការ
      ដូចជា ការផ្លាស់ទី ការបង្វិល ឬការពង្រីក។

   Header
   របារបញ្ជា
      របារនៅផ្នែកខាងលើ (ឬខាងក្រោម) នៃតំបន់មួយ ដែលផ្ទុកម៉ឺនុយ និងធាតុគ្រប់គ្រង
      សម្រាប់កម្មវិធីកែសម្រួលនោះ។ សូមមើល :doc:`/interface/window_system/regions`។

   Keymap
   ផែនទីគ្រាប់ចុច
      សំណុំនៃការផ្គូផ្គងរវាងផ្លូវកាត់គ្រាប់ចុច និង operator។ Blender មាន keymap លំនាំដើម
      និង *Industry Compatible*។ សូមមើល :doc:`/interface/keymap/index`។

   Material
   សម្ភារៈ
      ការកំណត់ថាផ្ទៃមួយមានរូបរាងដូចម្តេច — ពណ៌ ភាពរលោង ភាពថ្លា និងប្រតិកម្មជាមួយពន្លឺ។

   Mesh
      ប្រភេទ geometry ដែលបង្កើតឡើងពីកំពូល (vertex) ជ្រុង (edge) និងមុខ (face)។

   Mode
   របៀប
      ស្ថានភាពធ្វើការរបស់កម្មវិធីកែសម្រួល ដែលកំណត់ថាឧបករណ៍អ្វីខ្លះអាចប្រើបាន។
      ឧទាហរណ៍ *Object Mode*, *Edit Mode*, *Sculpt Mode*។

   Modifier
      កម្មវិធីកែប្រែ
      ប្រតិបត្តិការដែលផ្លាស់ប្ដូរ geometry ឬលក្ខណៈរបស់វត្ថុដោយស្វ័យប្រវត្តិ និងមិនបំផ្លាញទិន្នន័យដើម
      (non-destructive) ឧទាហរណ៍ *Subdivision Surface*, *Mirror*, *Boolean*។

   Node
   ថ្នាំង
      ប្លុកមុខងារមួយក្នុងប្រព័ន្ធ node ដែលភ្ជាប់គ្នាតាមរយៈខ្សែ (link) ដើម្បីបង្កើតលទ្ធផល។
      ប្រើក្នុង Geometry Nodes, Shader Nodes និង Compositing។

   Object
   វត្ថុ
      ធាតុមួយនៅក្នុងឆាក ដែលផ្ទុក data-block មួយ (mesh, curve, light, camera ជាដើម)
      រួមនឹងទីតាំង ការបង្វិល និងមាត្រដ្ឋានរបស់វា។

   Operator
   ប្រតិបត្តិករ
      ប្រតិបត្តិការមួយរបស់ Blender ដែលអាចបញ្ជាតាមម៉ឺនុយ ប៊ូតុង ផ្លូវកាត់គ្រាប់ចុច
      ឬ Python (``bpy.ops.*``)។ សូមមើល :doc:`/interface/operators`។

   Panel
   ផ្ទាំង
      ប្លុកព័ត៌មាន ឬធាតុគ្រប់គ្រងដែលអាចបង្រួម/ពង្រីកបាន នៅក្នុង sidebar ឬ header។
      សូមមើល :doc:`/interface/window_system/tabs_panels`។

   Preferences
   ចំណូលចិត្ត
      ការកំណត់កម្រិតកម្មវិធីរបស់ Blender (មិនមែនកម្រិតឯកសារ) ដូចជា ភាសា theme
      ផ្លូវកាត់គ្រាប់ចុច និងផ្លូវឯកសារ។ បើកបានដោយ :kbd:`Ctrl-Comma`។

   Property
   លក្ខណសម្បត្តិ
      តម្លៃមួយដែលអាចកំណត់បានរបស់វត្ថុ ឬ data-block ឧទាហរណ៍ ទីតាំង ពណ៌ ឬចំនួន។
      ក្នុង Python សំដៅដោយ ``bpy.types.*``។

   Region
   តំបន់រង
      ផ្នែកខាងក្នុងនៃតំបន់ (area) មួយ ដូចជា header, toolbar, sidebar
      និងផ្ទាំងមើលធំ (main region)។ សូមមើល :doc:`/interface/window_system/regions`។

   Render
      ដំណើរការគណនាឆាក 3D ទៅជារូបភាព ឬវីដេអូ 2D។ Blender មានម៉ាស៊ីន render
      ចម្បងពីរគឺ EEVEE និង Cycles។

   Rigging
      ដំណើរការបង្កើតឆ្អឹង (armature) និងការភ្ជាប់ (skin) ទៅនឹង mesh
      ដើម្បីធ្វើឱ្យតួអង្គអាចធ្វើចលនាបាន។

   Scene
   ឆាក
      ធុងផ្ទុកវត្ថុ ពន្លឺ កាមេរ៉ា និងការកំណត់ render។ ឯកសារ ``.blend`` មួយអាចមានឆាកច្រើន។

   Sculpting
   ការឆ្លាក់
      របៀបធ្វើការដែលកែរូបរាង mesh ដោយប្រើ brush ដូចការឆ្លាក់ដីឥដ្ឋពិត។

   Session
   វគ្គ
      ការប្រើប្រាស់ Blender មួយលើក ចាប់ពីបើកកម្មវិធីរហូតដល់បិទ។ Blender អាចរក្សាទុក
      និងស្ដារវគ្គចុងក្រោយឡើងវិញបាន ប្រសិនបើកម្មវិធីគាំង។

   Shader
      កម្មវិធី ឬបណ្ដាញ node ដែលកំណត់ពីរបៀបដែលផ្ទៃមួយធ្វើអន្តរកម្មជាមួយពន្លឺ
      (ពណ៌ ការជះពន្លឺត្រឡប់ ភាពគ្រើមគ្រោះ ជាដើម)។

   Shortcut
   ផ្លូវកាត់
      ការចុចគ្រាប់ចុច ឬបន្សំគ្រាប់ចុច ដែលបញ្ជា operator មួយដោយផ្ទាល់។

   Status Bar
   របារស្ថានភាព
      របារនៅបាតបង្អួច Blender ដែលបង្ហាញព័ត៌មានអំពីប្រតិបត្តិការបច្ចុប្បន្ន
      ការណែនាំ និងស្ថានភាពប្រព័ន្ធ។ សូមមើល :doc:`/interface/window_system/status_bar`។

   Tab
      ផ្ទាំងចុចនៅផ្នែកខាងលើនៃ sidebar ឬបន្ទះការកំណត់ ដែលប្ដូររវាងក្រុម panel។

   Texture
   វាយនភាព
      ទិន្នន័យរូបភាព ឬ procedural ដែលផ្ដល់ព័ត៌មានលម្អិតផ្ទៃដល់សម្ភារៈ (material)។

   Toolbar
   របារឧបករណ៍
      របារបញ្ឈរនៅខាងឆ្វេងនៃតំបន់មួយ ដែលផ្ទុកឧបករណ៍សម្រាប់របៀប (mode) បច្ចុប្បន្ន។
      សូមមើល :doc:`/interface/tool_system`។

   Tooltip
   ប្រអប់ព័ត៌មាន
      ប្រអប់អក្សរតូចដែលលោតឡើងនៅពេលដាក់ទ្រនិចកណ្ដុរលើធាតុគ្រប់គ្រងមួយ។
      សូមមើល :doc:`/getting_started/help`។

   Topbar
   របារកំពូល
      របារនៅផ្នែកខាងលើបំផុតនៃបង្អួច Blender ដែលផ្ទុកម៉ឺនុយធំៗ
      (:menuselection:`File`, :menuselection:`Edit` ជាដើម)។
      សូមមើល :doc:`/interface/window_system/topbar`។

   UV
      កូអរដោនេ 2D ដែលផ្គូផ្គងផ្ទៃ mesh ទៅនឹងរូបភាព texture។ អក្សរ U និង V
      សំដៅលើអ័ក្សទទឹង និងអ័ក្សបណ្ដោយនៃ texture (ជំនួសឱ្យ X, Y, Z)។

   Undo
      បោះបង់
      ការត្រឡប់ទៅស្ថានភាពមុន។ *Redo* គឺធ្វើឡើងវិញនូវអ្វីដែលបានបោះបង់។
      សូមមើល :doc:`/interface/undo_redo`។

   Vertex
   កំពូល
      ចំណុចមួយក្នុងលំហ 3D ដែលជាធាតុមូលដ្ឋានបំផុតនៃ mesh។

   Viewport
   ផ្ទាំងមើល
      តំបន់ដែលបង្ហាញឆាក 3D ហើយអនុញ្ញាតឱ្យរុករក និងកែសម្រួល។

   Workspace
   តំបន់ការងារ
      ការរៀបចំបង្អួចទាំងមូលដែលបានរក្សាទុកជាមុន (ឧទាហរណ៍ *Layout*, *Modeling*, *Sculpting*)
      ដែលអាចប្ដូរបានតាមរយៈ tab នៅរបារកំពូល។
      សូមមើល :doc:`/interface/window_system/workspaces`។
