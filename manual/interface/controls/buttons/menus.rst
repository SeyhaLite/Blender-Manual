.. _ui-menus:

###################
  ម៉ឺនុយ (Menus)
###################

Blender ប្រើម៉ឺនុយជាច្រើនប្រភេទ ដើម្បីឱ្យអ្នកចូលប្រើជម្រើស និង Operator ផ្សេងៗ។ អ្នកអាចប្រើម៉ឺនុយតាមវិធីខាងក្រោម៖

Mouse Selection
   ចុច :kbd:`LMB` លើធាតុដែលអ្នកចង់ជ្រើសរើស។

Numerical Selection
   អ្នកអាចប្រើគ្រាប់ចុចលេខ ឬ Numpad ដើម្បីជ្រើសរើសធាតុក្នុងបញ្ជី។ ឧទាហរណ៍ :kbd:`Numpad1` នឹងជ្រើសរើសធាតុទីមួយ។

   ប្រសិនបើម៉ឺនុយមានធាតុច្រើនពេករហូតមិនអាចបង្ហាញទាំងអស់លើអេក្រង់ នឹងមានសញ្ញាត្រីកោណតូចមួយសម្រាប់រមូរនៅផ្នែកខាងលើ ឬខាងក្រោមម៉ឺនុយ។ ដើម្បីរមូរ សូមផ្លាស់ទីកណ្ដុរទៅខាងលើ ឬខាងក្រោមសញ្ញានោះ។

Shortcuts
   - ប្រើកង់កណ្ដុរ :kbd:`Wheel` នៅពេលដាក់ទ្រនិចលើម៉ឺនុយ។
   - ប្រើគ្រាប់ចុចព្រួញ ដើម្បីរុករកធាតុក្នុងម៉ឺនុយ។
   - ធាតុម៉ឺនុយនីមួយៗមានអក្សរមួយដែលគូសបន្ទាត់ពីក្រោម។ ចុចអក្សរនោះ ដើម្បីបើកធាតុដែលត្រូវគ្នា។
   - អ្នកក៏អាចប្រើគ្រាប់ចុចលេខ ឬ Numpad ដើម្បីបើកធាតុម៉ឺនុយបានដែរ។ ឧទាហរណ៍ :kbd:`1` សម្រាប់ធាតុទីមួយ និង :kbd:`2` សម្រាប់ធាតុទីពីរ។ សម្រាប់ធាតុលេខ 11 ដល់ 20 ប្រើ :kbd:`Alt-1` ដល់ :kbd:`Alt-0`។
   - ចុច :kbd:`Return` ដើម្បីបើកធាតុដែលបានជ្រើសរើស។
   - ចុច :kbd:`Esc` ដើម្បីបិទម៉ឺនុយដោយមិនបើកធាតុណាមួយ។ អ្នកក៏អាចផ្លាស់ទីទ្រនិចកណ្ដុរឱ្យឆ្ងាយពីម៉ឺនុយ ឬចុច :kbd:`LMB` នៅខាងក្រៅម៉ឺនុយបានដែរ។

Popup Menus
===========

.. /images/interface_controls_buttons_menus_menu-button.png
.. figure:: https://docs.blender.org/manual/en/5.2/_images/interface_controls_buttons_menus_menu-button.png
   :alt: Image menu in the Image Editor header.
   :align: right

   ម៉ឺនុយ Image នៅក្នុងរបារបញ្ជា (Header) របស់ Image Editor។

Popup Menu បង្ហាញបញ្ជី Operator ដែលអ្នកអាចដំណើរការដោយចុច :kbd:`LMB` លើធាតុ ឬប្រើផ្លូវកាត់ដែលបានបង្ហាញដោយអក្សរគូសបន្ទាត់ពីក្រោមនៅក្នុងឈ្មោះ Operator។ ធាតុម៉ឺនុយនីមួយៗក៏បង្ហាញផ្លូវកាត់ដែលពាក់ព័ន្ធផងដែរ។ អ្នកអាចប្រើផ្លូវកាត់ទាំងនេះដោយមិនចាំបាច់បើកម៉ឺនុយជាមុន។

អ្នកអាចស្វែងរកក្នុង Popup Menu ដោយចុច :kbd:`Spacebar` រួចវាយឈ្មោះ Operator។ ប្រសិនបើ Popup Menu មានធាតុ *Search* ស្រាប់ អ្នកអាចស្វែងរកដោយមិនចាំបាច់ចុច :kbd:`Spacebar` ជាមុនទេ។

អ្នកក៏អាចប្រើមុខងារ Menu Search ដើម្បីស្វែងរក Popup Menu ទាំងអស់របស់ Editor មួយបានដែរ។

Select Menus
============

.. /images/interface_controls_buttons_menus_select-menu.png
.. figure:: https://docs.blender.org/manual/en/5.2/_images/interface_controls_buttons_menus_select-menu.png
   :alt: The 3D Viewport Mode Select menu.
   :align: right

   ម៉ឺនុយជ្រើសរើស Mode នៅក្នុង 3D Viewport។

Select Menu (ឬហៅថា Selector) អនុញ្ញាតឱ្យអ្នកជ្រើសរើសជម្រើសមួយពីបញ្ជីដែលបានកំណត់ជាមុន។ វាបង្ហាញជាឈ្មោះអក្សរ និង/ឬរូបតំណាង ដែលមានព្រួញចង្អុលចុះនៅខាងស្ដាំ។

ចុច :kbd:`LMB` ដើម្បីបើកម៉ឺនុយ រួចជ្រើសរើសជម្រើសដែលអ្នកត្រូវការ។ ជម្រើសដែលបានជ្រើសរើសនឹងបង្ហាញនៅក្នុងប៊ូតុង។ អ្នកក៏អាចប្ដូររវាងជម្រើសដោយមិនចាំបាច់បើកម៉ឺនុយបានដែរ ដោយរមូរកង់កណ្ដុរ :kbd:`Ctrl-Wheel` នៅលើប៊ូតុង។

-------------

   :alt: Expanded menu view.

Select Menu មួយចំនួនប្រើទម្រង់ពង្រីក ដើម្បីបង្ហាញជម្រើសទាំងអស់ក្នុងពេលតែមួយ។ ក្នុងទម្រង់នេះ ជម្រើសដែលកំពុងសកម្មត្រូវបានបន្លិចដោយពណ៌ផ្ទៃខាងក្រោយ។

ក្នុងករណីខ្លះ អ្នកអាចជ្រើសរើសជម្រើសច្រើនក្នុងពេលតែមួយ ដោយសង្កត់ :kbd:`Shift` ហើយចុច :kbd:`LMB` លើជម្រើសនីមួយៗ។

Context Menu
============

Context Menu ជាម៉ឺនុយលោតឡើងដែលអាចបើកដោយចុច :kbd:`RMB`។ នៅក្នុង Editor ភាគច្រើន អ្នកក៏អាចប្រើគ្រាប់ចុច :kbd:`Menu` បានដែរ។ ខ្លឹមសាររបស់ម៉ឺនុយអាស្រ័យលើទីតាំងដែលទ្រនិចកណ្ដុរស្ថិតនៅ។

នៅពេលបើកក្នុង Editor ម៉ឺនុយនឹងបង្ហាញបញ្ជី Operator ដែលសមស្របនឹង Mode របស់ Editor នោះ។ នៅពេលបើកលើប៊ូតុង និង Property ជម្រើសទូទៅអាចមានដូចខាងក្រោម៖

Single
   អនុវត្តការផ្លាស់ប្ដូរទៅលើតម្លៃតែមួយក្នុងសំណុំតម្លៃ (ឧទាហរណ៍ តែសំរបសំរួលអ័ក្ស X នៃ Location របស់វត្ថុប៉ុណ្ណោះ)។

All
   អនុវត្តការផ្លាស់ប្ដូរទៅលើតម្លៃទាំងអស់ក្នុងសំណុំ (ឧទាហរណ៍ សំរបសំរួលទាំងអស់នៃ Location របស់វត្ថុ)។

Reset to Default Value(s) :kbd:`Backspace`
   ជំនួសតម្លៃបច្ចុប្បន្នដោយតម្លៃលំនាំដើម។

Copy Data Path :kbd:`Shift-Ctrl-C`
   ចម្លងផ្លូវទិន្នន័យ (data path) របស់ Python Property ដែលទាក់ទងនឹង Data-Block។ មុខងារនេះមានប្រយោជន៍សម្រាប់ការសរសេរ Python Script។

Copy Full Data Path :kbd:`Shift-Ctrl-Alt-C`
   ចម្លងផ្លូវទិន្នន័យពេញលេញរបស់ Python Property រួមទាំងព័ត៌មាន Context ដែលត្រូវការ។

Copy As New Driver
   បង្កើត Driver ថ្មីមួយដោយប្រើ Property នេះជាតម្លៃបញ្ចូល រួចចម្លងវាទៅ Clipboard។ ប្រើ *Paste Driver* ដើម្បីបន្ថែម Driver ទៅ Property មួយទៀត ឬប្រើ *Paste Driver Variables* ដើម្បីបន្ថែមអថេរបញ្ចូលថ្មីទៅ Driver ដែលមានស្រាប់។

Copy To Selected
   ចម្លងតម្លៃ Property ទៅកាន់ Property ដែលត្រូវគ្នារបស់វត្ថុដែលបានជ្រើសរើស។ វាមានប្រយោជន៍នៅពេល Context របស់ Properties Editor ត្រូវបាន Pin ទុក។

Assign Shortcut
   អនុញ្ញាតឱ្យអ្នកកំណត់ផ្លូវកាត់ក្ដារចុច ឬកណ្ដុរសម្រាប់ប្រតិបត្តិការមួយ។ ដើម្បីកំណត់ផ្លូវកាត់ សូមផ្លាស់ទីទ្រនិចកណ្ដុរទៅលើប៊ូតុងដែលលោតឡើងជាមុនសិន។ នៅពេលបង្ហាញពាក្យ *Press a key* សូមចុចគ្រាប់ចុច ឬបន្សំគ្រាប់ចុចដែលអ្នកចង់ប្រើ។ ចុច :kbd:`Esc` ដើម្បីបោះបង់។

Change Shortcut
   អនុញ្ញាតឱ្យអ្នកកំណត់ផ្លូវកាត់ដែលមានស្រាប់ឡើងវិញ។

Remove Shortcut
   ដកការភ្ជាប់ផ្លូវកាត់ដែលមានស្រាប់ចេញ។

Open File Location, Open Location Externally
   បើកថតដែលផ្ទុកឯកសារនោះដោយប្រើ File Manager របស់ប្រព័ន្ធប្រតិបត្តិការ។

Online Manual :kbd:`F1`
   បើកទំព័រមួយនៅក្នុង Blender Manual តាមរយៈ Web Browser។

Online Python Reference
   ចូលទៅកាន់ឯកសារយោង Python API ដែលសមស្របនឹង Context បច្ចុប្បន្ន។

Pie Menus
==========

Pie Menu គឺជាម៉ឺនុយដែលធាតុនីមួយៗត្រូវបានរៀបចំជារង្វង់ជុំវិញទីតាំងកណ្ដុរ។

.. /images/interface_controls_buttons_menus_pie-menu.png
.. figure:: https://docs.blender.org/manual/en/5.2/_images/interface_controls_buttons_menus_pie-menu.png
   :alt: The 3D Viewport Mode Pie menu.
   :align: right

   Pie Menu របស់ Mode នៅក្នុង 3D Viewport។

.. tip::

   វិធីលឿនបំផុតក្នុងការប្រើ Pie Menu គឺសង្កត់គ្រាប់ចុចដែលបើកម៉ឺនុយ រួចផ្លាស់ទីកណ្ដុរបន្តិចទៅទិសនៃជម្រើសដែលអ្នកចង់បាន ហើយលែងគ្រាប់ចុច ដើម្បីបើកជម្រើសនោះ។

   ប្រសិនបើអ្នកលែងគ្រាប់ចុចដោយមិនផ្លាស់ទីកណ្ដុរ ម៉ឺនុយនឹងនៅបើក ដើម្បីឱ្យអ្នកចុចជ្រើសរើសធាតុដែលចង់បាន។ ប្រសិនបើអ្នកផ្លាស់ទីកណ្ដុរមុនពេលលែងគ្រាប់ចុច ធាតុដែលនៅជិតទិសកណ្ដុរបំផុតនឹងត្រូវបានបើកភ្លាមៗ។

Widget រាងថាសដែលបើកនៅកណ្ដាល Pie Menu បង្ហាញទិសដៅបច្ចុប្បន្នរបស់ម៉ឺនុយ។ ធាតុដែលបានជ្រើសរើសក៏ត្រូវបានបន្លិចផងដែរ។ Pie Menu អាចជ្រើសរើសធាតុតាមទិសដៅបាន លុះត្រាតែកណ្ដុរប៉ះ ឬលាតសន្ធឹងហួសពី Widget រាងថាសនៅកណ្ដាលម៉ឺនុយ។

ធាតុនៅក្នុង Pie Menu គាំទ្រ Key Accelerator ដែលជាអក្សរគូសបន្ទាត់ពីក្រោមនៅលើធាតុនីមួយៗ។ អ្នកក៏អាចប្រើគ្រាប់ចុចលេខបានដែរ។

ប្រសិនបើមាន Pie Menu រង នោះវានឹងត្រូវបានសម្គាល់ដោយរូបតំណាងបូក (+)។
