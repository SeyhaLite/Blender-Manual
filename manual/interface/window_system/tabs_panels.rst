ផ្ទាំងចុច (Tabs)
=================

.. figure:: /images/interface_window-system_tabs-panels_tabs.png
   :align: right
   :figwidth: 300px

   ខាងលើ៖ បញ្ជីផ្ទាំងចុចផ្ដេកនៅក្នុងរបារកំពូល (Topbar)។
   ខាងក្រោម៖ បញ្ជីផ្ទាំងចុចបញ្ឈរ បង្ហាញរូបតំណាងផ្ទាំងចុចក្នុង Properties។

ផ្ទាំងចុច (Tab) ត្រូវបានប្រើដើម្បីគ្រប់គ្រងផ្នែកដែលដាក់លើគ្នានៅក្នុងចំណុចប្រទាក់អ្នកប្រើ។
មាតិការបស់តែ Tab មួយប៉ុណ្ណោះដែលមើលឃើញក្នុងពេលតែមួយ។
Tab ត្រូវបានរាយក្នុង *បញ្ជីផ្ទាំងចុច (Tab header)* ដែលអាចជាផ្ដេក ឬបញ្ឈរ។


ការប្ដូរ/ការជុំវិញ
-------------------

Tab បញ្ឈរអាចត្រូវបានប្ដូរដោយ :kbd:`Ctrl-Wheel` ពីកន្លែងណាក៏បានក្នុង Tab។
អ្នកក៏អាចជុំវិញតាម Tab ដោយ :kbd:`Ctrl-Tab` និង :kbd:`Shift-Ctrl-Tab`
ឬសង្កត់ :kbd:`LMB` ហើយផ្លាស់ទីកណ្ដុរលើរូបតំណាងក្នុងបញ្ជីផ្ទាំងចុច។
ការចុច :kbd:`NumpadPeriod` រំកិលទៅ Tab សកម្ម ក្នុងករណីដែលវាមិនមើលឃើញ។

ចំណាំថា ផ្លូវកាត់ទាំងនេះមិនអនុវត្តចំពោះ Tab របស់ Workspace ទេ;
សូមមើល :ref:`ការគ្រប់គ្រង Workspace <workspaces-controls>`។

ផ្ទាំង (Panels)
================

.. figure:: /images/interface_window-system_tabs-panels_panels.png
   :align: right
   :figwidth: 200px

   ផ្ទាំងនៅក្នុង Properties។

   ផ្ទាំងមួយត្រូវបានបន្លិចជាពណ៌លឿង និងអនុផ្ទាំង (subpanel) មួយជាពណ៌ក្រហម។

ឯកតារៀបចំតូចបំផុតក្នុងចំណុចប្រទាក់អ្នកប្រើ គឺផ្ទាំង (panel)។
បញ្ជីផ្ទាំង (panel header) បង្ហាញចំណងជើងរបស់ផ្ទាំង។ វាបង្ហាញជានិច្ច។
ផ្ទាំងខ្លះក៏មានអនុផ្ទាំងផងដែរ។


ការបង្រួម និងការពង្រីក
------------------------

ផ្ទាំងមួយអាចត្រូវបានពង្រីកដើម្បីបង្ហាញមាតិការបស់វា ឬបង្រួមដើម្បីលាក់មាតិការបស់វា។
ផ្ទាំងដែលបានពង្រីកត្រូវបានបង្ហាញដោយព្រួញចុះក្រោម (▼) នៅក្នុងបញ្ជីផ្ទាំង
ខណៈដែលផ្ទាំងដែលបានបង្រួមបង្ហាញដោយព្រួញទៅស្ដាំ (►)។

- ការចុច :kbd:`LMB` លើបញ្ជីផ្ទាំង ពង្រីក ឬបង្រួមវា។
- ការចុច :kbd:`A` ពង្រីក/បង្រួមផ្ទាំងដែលនៅក្រោមទ្រនិចកណ្ដុរ។
- ការចុច :kbd:`Ctrl-LMB` លើបញ្ជីផ្ទាំងដែលបានបង្រួម នឹងពង្រីកវា និងបង្រួមផ្ទាំងទាំងអស់ផ្សេងទៀត។
- ការចុច :kbd:`Ctrl-LMB` លើបញ្ជីផ្ទាំងដែលបានពង្រីក នឹងពង្រីក/បង្រួមអនុផ្ទាំងទាំងអស់របស់វា។
- ការអូសដោយ :kbd:`LMB` លើបញ្ជីផ្ទាំង នឹងពង្រីក ឬបង្រួមច្រើនក្នុងពេលតែមួយ។


ទីតាំង
-------

អ្នកអាចផ្លាស់ប្ដូរទីតាំងផ្ទាំងមួយនៅក្នុងតំបន់រងរបស់វា ដោយចុចហើយអូស
widget កាន់ (\\:\\:\\:\\:) នៅផ្នែកខាងស្ដាំនៃបញ្ជីផ្ទាំងរបស់វា។


ការខ្ទាស់ (Pinning)
-------------------

ជួនកាលវាចង់បានក្នុងការមើលផ្ទាំងពី Tab ផ្សេងៗគ្នាក្នុងពេលតែមួយ។
ឧទាហរណ៍ ការមានសិទ្ធិចូលប្រើលក្ខណសម្បត្តិរបស់កាមេរ៉ា ខណៈដែលវត្ថុផ្សេងទៀតត្រូវបានជ្រើសរើស។
បញ្ហានេះត្រូវបានដោះស្រាយដោយធ្វើឱ្យផ្ទាំងអាចខ្ទាស់ (pin) បាន។

ផ្ទាំងដែលបានខ្ទាស់ នៅតែមើលឃើញ មិនថា Tab ណាត្រូវបានជ្រើសរើសទេ។
អ្នកអាចខ្ទាស់ផ្ទាំងមួយដោយចុចលើរូបតំណាងខ្ទាស់នៅក្នុងបញ្ជីផ្ទាំងរបស់វា។
ផ្ទាំងដែលគ្មានរូបតំណាងខ្ទាស់ អាចត្រូវបានខ្ទាស់ដោយចុច :kbd:`RMB` លើបញ្ជីផ្ទាំង
ហើយជ្រើសរើស *Pin* ឬដោយចុច :kbd:`Shift-LMB`។

.. note::

   ការខ្ទាស់មិនមានសម្រាប់ផ្ទាំងទាំងអស់ទេ។ ឧទាហរណ៍ វាមាននៅក្នុង Sidebar
   ប៉ុន្តែមិនមាននៅក្នុង Properties editor ទេ។

Preset
------

ផ្ទាំងនៅក្នុង Blender ផ្ដល់ម៉ឺនុយ **Presets** (:bl-icon:`preset`)
សម្រាប់ប្រើការកំណត់ទូទៅឡើងវិញយ៉ាងរហ័ស។
Preset អាចសន្សំពេលវេលាដោយរក្សាទុកការកំណត់ដែលប្រើញឹកញាប់
ដែលបន្ទាប់មកអាចអនុវត្តឡើងវិញបានដោយចុចតែម្ដង។

.. figure:: /images/interface_controls_templates_list-presets_preset.png
   :align: center

   ឧទាហរណ៍ម៉ឺនុយ Preset។


Selector :bl-icon:`preset`
   បញ្ជី preset ដែលមាន។ ការជ្រើសរើសមួយនឹងអនុវត្តតម្លៃដែលបានរក្សាទុក
   ទៅលក្ខណសម្បត្តិដែលពាក់ព័ន្ធ។

   .. _bpy.types.WindowManager.preset_name:

   Preset Name
      ឈ្មោះដែលត្រូវប្រើនៅពេលបន្ថែម preset ថ្មី។
   :bl-icon:`add` (Add)
      បង្កើត preset ថ្មីដោយប្រើការកំណត់បច្ចុប្បន្ន
      បន្ទាប់មក preset នោះត្រូវបានរក្សាទុក ហើយលេចឡើងក្នុងបញ្ជីសម្រាប់ប្រើឡើងវិញនាពេលអនាគត។
   :bl-icon:`remove` (Remove)
      លុប preset ដែលបានជ្រើសរើស។

Preset ត្រូវបានរក្សាទុកជាឯកសារ Python ក្នុង
`ថតកំណត់រចនាសម្ព័ន្ធ <https://docs.blender.org/manual/en/5.2/advanced/blender_directory_layout.html#blender-directory-path-layout>`__
របស់ Blender។ អ្នកប្រើកម្រិតខ្ពស់អាចកែឯកសារ preset ទាំងនេះដោយផ្ទាល់
ដើម្បីកែតម្រូវការកំណត់ឱ្យល្អិតល្អន់ ឬចម្លងវាទៅប្រព័ន្ធផ្សេងទៀត។
