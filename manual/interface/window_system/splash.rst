###################################################
  អេក្រង់ចាប់ផ្ដើម (Splash Screen)
###################################################

នៅពេលបើក Blender អេក្រង់ចាប់ផ្ដើម (splash screen) លេចឡើងនៅកណ្ដាលបង្អួច។
វាមានជម្រើសដើម្បីបង្កើតគម្រោងថ្មី ឬបើកគម្រោងថ្មីៗ។
ការពណ៌នាលម្អិតបន្ថែមមាននៅខាងក្រោម។

.. figure:: /images/interface_splash_current.webp
   :align: center

   អេក្រង់ចាប់ផ្ដើមរបស់ Blender។

ដើម្បីបិទអេក្រង់ចាប់ផ្ដើម និងចាប់ផ្ដើមគម្រោងថ្មី
សូមចុចនៅកន្លែងណាមួយខាងក្រៅអេក្រង់ចាប់ផ្ដើម (ប៉ុន្តែខាងក្នុងបង្អួច Blender) ឬចុច :kbd:`Esc`។
អេក្រង់ចាប់ផ្ដើមនឹងបាត់ទៅវិញ ដោយបង្ហាញអេក្រង់លំនាំដើម។
ដើម្បីបើកអេក្រង់ចាប់ផ្ដើមឡើងវិញ សូមចុចលើរូបតំណាង Blender នៅរបារកំពូល ហើយជ្រើសរើស *Splash Screen*។

.. note::

   នៅពេលបើក Blender ជាលើកដំបូង ឬធ្វើបច្ចុប្បន្នភាពទៅកំណែថ្មី
   «តំបន់អន្តរកម្ម» នឹងមាន :ref:`ដំណើរការកំណត់រហ័ស <splash-quick-start>`។


រូបភាពអេក្រង់ចាប់ផ្ដើម
======================

ផ្នែកខាងលើនៃអេក្រង់ចាប់ផ្ដើម មានរូបភាពអេក្រង់ចាប់ផ្ដើម
ជាមួយកំណែរបស់ Blender នៅជ្រុងខាងលើផ្នែកខាងស្ដាំ។


តំបន់អន្តរកម្ម
==============

តំបន់អន្តរកម្មគឺជាពាក់កណ្ដាលខាងក្រោមនៃអេក្រង់ចាប់ផ្ដើម។

New File
   ចាប់ផ្ដើមគម្រោងថ្មីដោយផ្អែកលើគំរូ (template) មួយ។
Recent Files
   ឯកសារ ``.blend`` ដែលអ្នកបានបើកថ្មីៗបំផុត។ នេះផ្ដល់ការចូលប្រើរហ័ស និងងាយស្រួល
   ទៅកាន់គម្រោងថ្មីៗរបស់អ្នក។

Open
   អនុញ្ញាតឱ្យបើកឯកសារ ``.blend`` ដែលមានស្រាប់។
Recover Last Session
   Blender នឹងព្យាយាមស្ដារ :term:`វគ្គ (session) <session>` ចុងក្រោយ
   ដោយផ្អែកលើឯកសារបណ្ដោះអាសន្ន។ សូមមើល
   `Recovering Data <https://docs.blender.org/manual/en/5.2/troubleshooting/recover.html>`__។

What's New
   បើកកំណត់ត្រាការចេញផ្សាយចុងក្រោយ។
Donate to Blender
   បើកគេហទំព័រ `Development Fund <https://fund.blender.org/>`__ របស់ Blender។
