បន្ទាប់ពីបើក Blender និងបិទ :ref:`អេក្រង់ចាប់ផ្ដើម (Splash Screen) <splash>`
បង្អួច Blender គួរតែមើលទៅស្រដៀងនឹងរូបភាពខាងក្រោម។

.. figure:: /images/interface_window-system_introduction_default-startup.webp
   :align: center

   បង្អួច Blender លំនាំដើមនៅពេលចាប់ផ្ដើម។

ចំណុចប្រទាក់របស់ Blender ត្រូវបានបំបែកជាផ្នែកសំខាន់ៗបី៖

- :doc:`របារកំពូល (Topbar) </interface/window_system/topbar>` នៅផ្នែកខាងលើបំផុត
  ដែលមានម៉ឺនុយធំៗ ប្រើសម្រាប់រក្សាទុក នាំចូល និងនាំចេញឯកសារ កំណត់ការកំណត់
  និង render ក្នុងចំណោមមុខងារផ្សេងទៀត។
- :doc:`តំបន់ (Areas) </interface/window_system/areas>` នៅកណ្ដាល ដែលជាតំបន់ការងារចម្បង។
- :doc:`របារស្ថានភាព (Status Bar) </interface/window_system/status_bar>` នៅផ្នែកខាងក្រោម
  ដែលបង្ហាញការណែនាំផ្លូវកាត់ និងស្ថិតិពាក់ព័ន្ធ។

   និងរបារស្ថានភាព (ពណ៌ក្រហម)។


ការប្ដូរតាមបំណង
================

.. rubric:: ផ្លូវកាត់ក្ដារចុច

Blender ប្រើផ្លូវកាត់ក្ដារចុចយ៉ាងច្រើន ដើម្បីធ្វើឱ្យការងាររហ័ស។
ទាំងនេះអាចប្ដូរតាមបំណងបានក្នុង
`Keymap Editor <https://docs.blender.org/manual/en/5.2/editors/preferences/keymap.html#prefs-input-keymap-editor>`__។


.. rubric:: ពណ៌រូបរាង (Theme colors)

Blender អនុញ្ញាតឱ្យប្ដូរពណ៌ចំណុចប្រទាក់ភាគច្រើនរបស់វា ដើម្បីឱ្យស្របតាមតម្រូវការអ្នកប្រើ។
ប្រសិនបើអ្នកឃើញថាពណ៌នៅលើអេក្រង់របស់អ្នកមិនត្រូវនឹងពណ៌ក្នុងសៀវភៅណែនាំទេ
វាអាចជារូបរាងលំនាំដើមរបស់អ្នកត្រូវបានកែប្រែ។
ការបង្កើតរូបរាងថ្មី ឬជ្រើសរើស/កែប្រែរូបរាងដែលមានស្រាប់ អាចធ្វើបានដោយបើក
`Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/index.html>`__
ហើយចុចលើផ្ទាំង *Themes*។

.. rubric:: ភាពអាចចូលដំណើរការបាន (Accessibility)

Blender មានជម្រើសជាច្រើនសម្រាប់ប្ដូរភាពមើលឃើញតាមបំណង
រួមទាំងមាត្រដ្ឋានគុណភាពបង្ហាញ (resolution scale) និងសមត្ថភាពផ្ទុកពុម្ពអក្សរផ្ទាល់ខ្លួន។
ការកំណត់ទាំងនេះអាចកំណត់បានក្នុង
`Interface Preferences <https://docs.blender.org/manual/en/5.2/editors/preferences/interface.html>`__។
