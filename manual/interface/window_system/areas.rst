##################
  តំបន់ (Areas)
##################

.. figure:: /images/interface_window-system_areas_borders.png
   :align: right
   :width: 250px
   :figwidth: 250px

   ព្រំដែនតំបន់ត្រូវបានបង្ហាញដោយជ្រុងមូល (ការបន្លិចពណ៌លឿង)។

បង្អួច Blender ត្រូវបានបំបែកជាចតុកោណកែងជាច្រើន ដែលហៅថាតំបន់ (Areas)។
តំបន់ទុកកន្លែងអេក្រង់សម្រាប់
`កម្មវិធីកែសម្រួល (Editors) <https://docs.blender.org/manual/en/5.2/editors/index.html>`__
ដូចជា `3D Viewport <https://docs.blender.org/manual/en/5.2/editors/3dview/introduction.html>`__
ឬ `Outliner <https://docs.blender.org/manual/en/5.2/editors/outliner/introduction.html>`__។
កម្មវិធីកែសម្រួលនីមួយៗផ្ដល់មុខងារជាក់លាក់មួយ។

តំបន់ត្រូវបានដាក់ជាក្រុមជា
:doc:`តំបន់ការងារ (Workspaces) </interface/window_system/workspaces>`
ដែលមានគោលដៅលើកិច្ចការជាក់លាក់ (modeling, animation ជាដើម)។

.. note::

   ទោះបីជាផ្លូវកាត់ក្ដារចុចខ្លះក្នុង Blender ជាសកលក៏ដោយ (ដូចជា :kbd:`Ctrl-S` សម្រាប់រក្សាទុក)
   ផ្លូវកាត់ជាច្រើនអាស្រ័យលើថាកម្មវិធីកែសម្រួលណាដែលទ្រនិចកណ្ដុរកំពុងស្ថិតនៅលើ។

   ជាឧទាហរណ៍ ឧបមាថាអ្នកទើបតែជ្រើសរើសវត្ថុពីរក្នុង Outliner ហើយចង់ភ្ជាប់វាចូលគ្នា។
   ប្រសិនបើអ្នកចុចផ្លូវកាត់សម្រាប់ការនេះ (:kbd:`Ctrl-J`) ខណៈដែលទ្រនិចនៅតែក្នុង Outliner
   គ្មានអ្វីកើតឡើងទេ ព្រោះផ្លូវកាត់នោះមិនមានសុពលភាពនៅទីនោះ;
   អ្នកត្រូវផ្លាស់ទីទ្រនិចទៅ 3D Viewport ជាមុនសិន។

.. tip::

   - ទំហំព្រំដែនជុំវិញតំបន់អាចកែបានក្នុងចំណូលចិត្តអ្នកប្រើ ដោយ
     :ref:`Border Width <bpy.types.PreferencesView.border_width>`។
   - ដៃចាប់ (Handle) អាចត្រូវបានបើកឱ្យបង្ហាញជានិច្ច ដែលអាចជួយក្នុងការគ្រប់គ្រងតំបន់
     លើឧបករណ៍ដែលមានអេក្រង់ប៉ះ។ សូមមើល :ref:`bpy.types.PreferencesView.show_area_handle`។

ការប្ដូរទំហំ (Resizing)
========================

.. figure:: /images/interface_window-system_areas_resize.png
   :align: right
   :width: 250px
   :figwidth: 250px

តំបន់អាចត្រូវបានប្ដូរទំហំដោយអូសព្រំដែនរបស់វាដោយ :kbd:`LMB`។
ផ្លាស់ទីទ្រនិចទៅលើព្រំដែនរវាងតំបន់ពីរ ដើម្បីឱ្យទ្រនិចប្ដូរទៅជាព្រួញពីរក្បាល
បន្ទាប់មកចុចហើយអូស។

- សង្កត់ :kbd:`Ctrl` ដើម្បីភ្ជាប់ទំហំតំបន់ទៅនឹងទំហំដែលងាយស្រួល។
- សង្កត់ :kbd:`Shift` ដើម្បីផ្លាស់ទីព្រំដែនដែលតម្រឹមនៅជិតៗគ្នាជាមួយគ្នា ខណៈពេលប្ដូរទំហំ។


ការភ្ជាប់ (Docking)
===================

Docking ពណ៌នាអំពីវិធីជាច្រើន ដែលអ្នកប្រើអាចគ្រប់គ្រងទំហំ និងទីតាំងនៃតំបន់
ដោយអន្តរកម្ម ព្រមទាំងបំបែកតំបន់មួយទៅជាតំបន់ថ្មី។

ដើម្បីចាប់ផ្ដើមដំណើរការអន្តរកម្ម ការដាក់ទ្រនិចកណ្ដុរនៅជ្រុងតំបន់មួយ
នឹងប្ដូរទ្រនិចទៅជាសញ្ញាឆ្កាវ (+)។
នៅពេលដែលទ្រនិចក្លាយជាសញ្ញាឆ្កាវ សូមចុចហើយសង្កត់ :kbd:`LMB` ដើម្បីធ្វើសកម្មភាពណាមួយខាងក្រោម៖

ប្រសិនបើអ្នកចុច :kbd:`Esc` ឬ :kbd:`RMB` មុនពេលលែងកណ្ដុរ ប្រតិបត្តិការនឹងត្រូវបានបោះបង់។

ការភ្ជាប់ចូលគ្នា (Joining)
---------------------------

.. figure:: /images/interface_window-system_areas_join.png

ការអូសពីជ្រុងតំបន់មួយចូលទៅក្នុងលំហនៃតំបន់ទីពីរ នឹង *ភ្ជាប់* តំបន់ពីរចូលគ្នា។
តំបន់ដែលនឹងត្រូវភ្ជាប់ នឹងបង្ហាញភ្លឺជាង។

ការបំបែក (Splitting)
---------------------

.. figure:: /images/interface_window-system_areas_split.png
   :align: right
   :width: 250px
   :figwidth: 250px

ការបំបែកតំបន់មួយនឹងបង្កើតតំបន់ថ្មី។
ការអូសពីជ្រុងតំបន់មួយទៅឆ្វេង/ស្ដាំ នឹងបំបែកតំបន់តាមបញ្ឈរ;
ដើម្បីបំបែកតំបន់តាមផ្ដេក សូមអូសឡើងលើ/ចុះក្រោម។

អ្នកអាចបំបែក និងភ្ជាប់តំបន់ក្នុងពេលតែមួយ ដោយអូសប្រតិបត្តិការបំបែក
ចូលទៅក្នុងតំបន់ដាច់ដោយឡែកមួយ។

ការអូសតំបន់មួយចូលទៅកណ្ដាលនៃតំបន់ទីពីរ នឹងជំនួសតំបន់ទីពីរដោយតំបន់ទីមួយ។


.. _bpy.ops.screen.area_options:

ជម្រើសតំបន់ (Area Options)
============================

ចុច :kbd:`RMB` លើព្រំដែន ដើម្បីបើក *Area Options*។

Vertical/Horizontal Split
   បង្ហាញបន្ទាត់សូចនាករ ដែលអនុញ្ញាតឱ្យអ្នកជ្រើសរើសតំបន់ និងទីតាំងដែលត្រូវបំបែក។
   :kbd:`Tab` ប្ដូររវាងបញ្ឈរ/ផ្ដេក។
Join Up/Down/Left/Right
   បង្ហាញស្រទាប់បន្ថែម (overlay) នៃទិសដៅភ្ជាប់។
Swap Areas
   ប្ដូរតំបន់នេះជាមួយតំបន់ជាប់គ្នា។


.. _bpy.ops.screen.area_swap:

ការប្ដូរខ្លឹមសារ (Swapping Contents)
=====================================

អ្នកអាចប្ដូរខ្លឹមសារនៃតំបន់ពីរ ដោយចុច :kbd:`Ctrl-LMB`
លើជ្រុងមួយនៃតំបន់ដើម អូសទៅរកតំបន់គោលដៅ ហើយលែងកណ្ដុរនៅទីនោះ។
តំបន់ទាំងពីរមិនចាំបាច់នៅជាប់គ្នាទេ ប៉ុន្តែវាត្រូវតែនៅក្នុងបង្អួចតែមួយ។


.. _bpy.ops.screen.screen_full_area:

ពង្រីកតំបន់អតិបរមា (Maximize Area)
=====================================

.. reference::

   :Menu:      :menuselection:`View --> Area --> Toggle Maximize Area`
   :Shortcut:  :kbd:`Ctrl-Spacebar`

ពង្រីកតំបន់កម្មវិធីកែសម្រួល ដើម្បីឱ្យវាបំពេញបង្អួចទាំងមូល
ដោយរក្សាទុកតែរបារម៉ឺនុយ និងរបារស្ថានភាពរបស់កម្មវិធីកែសម្រួលឱ្យនៅមើលឃើញ។
នេះមានប្រយោជន៍សម្រាប់ការផ្ដោតលើកម្មវិធីកែសម្រួលតែមួយ
(ឧទាហរណ៍ 3D Viewport, Shader Editor) ដោយមិនផ្លាស់ប្ដូរការរៀបចំតំបន់ការងាររបស់អ្នក។

ខុសពី :ref:`របៀបផ្ដោត (Focus Mode) <focus-mode>`
របារម៉ឺនុយ និងរបារស្ថានភាពរបស់កម្មវិធីកែសម្រួលនៅតែមើលឃើញ។

ដើម្បីត្រឡប់ទៅទំហំធម្មតា សូមប្រើផ្លូវកាត់ដដែល ឬចុចប៊ូតុង *Back to Previous* នៅក្នុងរបារកំពូល។

===========================

.. reference::

   :Menu:      :menuselection:`View --> Area --> Restore Area`
   :Shortcut:  :kbd:`Ctrl-Spacebar`

ត្រឡប់តំបន់ដែលបានពង្រីកអតិបរមា ទៅទំហំដើមរបស់វា ហើយស្ដារការរៀបចំអេក្រង់មុន។


.. _focus-mode:

របៀបផ្ដោត (Focus Mode)
========================

.. reference::

   :Menu:      :menuselection:`View --> Area --> Focus Mode`
   :Shortcut:  :kbd:`Ctrl-Alt-Spacebar`

ពង្រីកតំបន់កម្មវិធីកែសម្រួល ដើម្បីឱ្យវាបំពេញបង្អួចទាំងមូល ដោយលាក់៖

- របារកំពូល (Topbar)
- របារស្ថានភាព (Status Bar)
- :doc:`តំបន់រង (regions) </interface/window_system/regions>` រង
  (ដូចជា របារឧបករណ៍ របារចំហៀង របារបញ្ជា ជាដើម) របស់កម្មវិធីកែសម្រួលខ្លួនឯង។

របៀបនេះផ្ដល់កន្លែងអេក្រង់ច្រើនបំផុតដែលអាចធ្វើបាន សម្រាប់កម្មវិធីកែសម្រួលសកម្ម។

ដើម្បីត្រឡប់ទៅទំហំធម្មតា សូមប្រើផ្លូវកាត់ដដែល ឬចុចរូបតំណាង :bl-icon:`fullscreen_exit`
នៅជ្រុងខាងលើផ្នែកខាងស្ដាំនៃកម្មវិធីកែសម្រួល (មើលឃើញតែនៅពេលដាក់ទ្រនិចលើតំបន់ប៉ុណ្ណោះ)។


.. _bpy.ops.screen.area_dupli:

ចម្លងតំបន់ទៅបង្អួចថ្មី
========================

.. reference::

   :Menu:      :menuselection:`View --> Area --> Duplicate Area into New Window`

បង្កើតបង្អួចអណ្ដែតថ្មីមួយ ដែលមានច្បាប់ចម្លងនៃតំបន់កម្មវិធីកែសម្រួលបច្ចុប្បន្ន។
បង្អួចថ្មីនេះដំណើរការពេញលេញ និងជាផ្នែកមួយនៃ Blender instance ដូចគ្នា។

នេះមានប្រយោជន៍ជាពិសេស នៅពេលធ្វើការជាមួយអេក្រង់ច្រើន។

.. tip::

   អ្នកក៏អាចបង្កើតបង្អួចថ្មីបានដែរ ដោយសង្កត់ :kbd:`Shift-LMB` លើជ្រុងតំបន់មួយ
   ហើយអូសចេញក្រៅបន្តិច។
